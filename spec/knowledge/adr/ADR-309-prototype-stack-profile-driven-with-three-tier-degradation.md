# ADR-309：原型机制建立在栈画像上，资源加载三级降级且底档无约束力

date: 2026-11-02
status: accepted

## Context

界面原型要做到「真组件、假数据」高保真，但目标工程的组件栈多样，node 与外网环境不可假设。若把通用机制绑定在单一组件库（如 antd）上，机制随栈迁移即腐化；若无条件硬依赖 node 打包或 CDN，环境不满足时整条链路瘫痪或静默假冒高保真。

## Decision

通用原型机制建立在栈画像上而非具体组件库上：生成前侦察目标工程依赖清单、主题/设计 token 与 DESIGN.md 产出画像并注入生成 prompt，新栈支持等于新增画像识别、不动机体。真组件资源加载固定三级降级：skill 自维护的预打包 vendor 缓存（按组件库版本精确缓存、与工程无关，落 `.fenix/prototype-vendor/` 不入库）→ CDN ESM 兜底 → 纯 HTML/CSS 仿样。node 是优先条件而非硬假设；bootstrap 先做环境自检，逐级降级不硬崩；每一级降级对用户可见，底档仿样 MUST 显式标注「视觉参照、无约束力」，禁止静默假冒高保真。

## Consequences

- 栈扩展成本收敛为画像识别一条，机制本体稳定；画像数据结构留扩展位。
- vendor 缓存版本与工程钉版可能偏差：bootstrap 按侦察到的版本精确缓存，不命中回退打包或 CDN，降级路径可见。
- CDN 兜底依赖代理可达，缓存命中后离线可用；底档仿样丢失绑定力是显式声明的代价，不是缺陷。
