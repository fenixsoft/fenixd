# ADR-096：控制信号机器语义独立类型化 + 在途去重

date: 2026-09-15
status: accepted

## Context

同一端点的语义变体（契约缺失 vs 契约覆盖确认重起草）复用单一信号类型、仅以 evidence 字段区分时，按 signal_type 分派 severity 与处置指引的监测链路无法识别变体；前端按钮置位到渲染生效存在调度间隙（实证 100ms 双击穿透），服务端无幂等造成双发。

## Decision

- 机器消费语义走独立 signal_type，不以 evidence 字段标记变体：evidence 是人读溯源通道，机器语义不得依赖它。新类型零侵入接入既有分派——severity 表、处置指引表、摄取白名单、族式统计的提取条件四处注册点同步。
- 在途去重：同项目同类型 handled=false 的未处置信号存在时不重复写、响应注明在途；异类型互不抑制（契约修正后的覆盖确认是新的合法意图），已处置的历史信号不抑制（可再次请求）。
- 前端防重入用 ref 同步锁：写读同帧原子，不依赖渲染生效时机，finally 复位、组件卸载即销毁。

## Consequences

- 信号语义可被监测链路精确分派，无需解析 evidence 文本。
- 双发被前端锁与服务端幂等两端同时拦截。
- 去重读全量告警库在现有规模下开销可忽略，不引入索引；通用跨类型去重框架不做（仅本端点按需）。
