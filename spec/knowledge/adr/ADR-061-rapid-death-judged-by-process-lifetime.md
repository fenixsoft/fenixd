# ADR-061：run 瞬时死亡判定以进程存活时长为准，不解析退出码

date: 2026-09-10
status: accepted

## Context

环境性异常会引发 run 进程秒级连发死亡。按退出码分类不可靠：Exit 143/137/1 等码在不同环境语义不稳，SIGTERM 既可能是异常也可能来自 supervisor 的正常终止。瞬时死亡若被当作普通失败逐次重派，会形成无冷却的重派风暴。

## Decision

- run 瞬时死亡（秒挂）判定以**进程存活时长**为准：存活低于阈值秒即视为瞬时死亡，不解析、不依赖退出码。
- 被框架主动 SIGTERM 的 run（liveness/shutdown 路径已有标记）不计入秒挂。
- 连续秒挂达到阈值进入冷却窗口，冷却结束自动恢复重派；正常单次瞬时失败不受冷却影响。

## Consequences

- 环境性死亡风暴从无界连发收敛为「阈值 → 冷却 → 自动恢复」的有界节奏。
- 冷却会使冷却期内的正常重试延迟一个窗口——仅在连续秒挂成立后触发，是接受的代价。
