# 管理员运营与告警

管理员运营与告警。本域能力条目清单如下（能力页由存量回填批次逐步产出，落盘后此处升级为链接）。

## 能力页

- `administrator-agent` — 管理员 agent 角色与职责
- `administrator-model-assignment` — 管理员 agent 模型指派
- `admin-activity-view` — 管理员处置活动视图
- `admin-narrative-summary` — 处置记录叙事化摘要
- `admin-invoke-record-dialog` — admin 手工调用记录弹窗
- `admin-health-monitor` — 管理员健康监控视角
- `admin-monitor` — 异常状态探测口径（admin monitor 探针）
- `admin-monitoring` — 同 SPEC 同类型信号状态沉淀
- `admin-dispatch-failure` — admin 派发失败专用升级信号
- `admin-disposition-failure-context` — admin 处置失败上下文保全
- `admin-disposition-reschedule` — admin 处置后重新排期
- `admin-reset-error-escalation` — admin 重置后错误升级路径
- `add-spec-manual-admin-invoke` — SPEC 菜单发起管理员手工介入
- `manual-invoke-signal-passthrough` — 手工触发信号类型透传
- `adjudication-actions` — 人工裁决动作执行
- `adjudication-choices-registry` — 裁决选择题注册表
- `adjudication-ui` — 人工裁决操作界面
- `admin-choices-contract` — 裁决选择题 admin 侧契约
- `alert-lifecycle` — 告警生命周期与自动消解
- `alert-resolve` — 告警人工消解闭环
- `human-escalation-alerts` — 人工升级告警发出与节流
- `blocked-disposition-classification` — blocked 冻结/阻塞二分类机械化
- `stuck-signal-hygiene` — stuck 信号活跃度预检与处置后静默
