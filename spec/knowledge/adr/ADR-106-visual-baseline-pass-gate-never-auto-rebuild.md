# ADR-106：视觉基线固化过通过性门，污染只标记永不自动重建

date: 2026-09-17
status: accepted

## Context

视觉比对 flaky 有两大来源：截图时 opacity / transform 动画未静置（布局偏移检测对渐变完全不敏感），以及首轮基线无条件固化把「弹窗未出现」的污染态钉成基准——恒比恒低、非随机。基线一旦污染则每轮重演；而自动重建基线在「基线是对的、当前版本真回归」的镜像场景下会洗白回归。

## Decision

- 截图前动画静置落在视觉比对唯一入口内部（compare 内），页面注入 JS 等待全部动画 finished（上限读配置、0=禁用逃生门）；不在场景 / 步骤层外挂——唯一入口保证全量场景统一覆盖，步骤层静置语义不同、强加会放大时延。低分限次重拍取最高分（时序噪声单侧分布，择优取证），仍低维持原判不掩盖回归。
- 基线固化双门串联：健全性判定（blank / 低对比度拒固化）在前，场景通过性门在后——本轮步骤与断言未全过的场景返回 baseline_deferred 顺延固化，宁缺毋污染；deferred 沿 flaky / env 的「非打回」通道，不构成打回依据、不降档。
- 污染基线只标记不处置：每场景连续 diff_detected 达阈值发 admin 告警并写 suspicious 标记文件，任一轮恢复即清标记；**基线重建是人工确认动作，框架永不自动重建 / 覆盖已固化基线**。
- 新配置键收敛在 verify_engine 段、缺省向后兼容；settle / 重拍只在异常路径发生，干净场景首拍通过零附加开销。

## Consequences

- 固化门阻断污染基线新增；存量污染由 suspicious 告警指出，人工删基线文件后下轮重建干净基线。
- 首轮有失败场景的基线顺延一轮建立，语义即宁缺毋污染；告警只是提醒人工核实，不自动处置。
