# ADR-365：token 预算治理制动模型——告警分级进人工队列 + 判定面额度压缩，预算面零自动冻结

date: 2026-11-16
status: accepted

## Context

spec 级 token 预算的既有治理动作只有 warning 告警（80%/100% 两档均警告级、明文不自动冻结），judge 重跑上限只封判定次数不封 token。实锤案例：单个重型 spec 预算烧至 99.9%（100M 预算）全程仅两条 warning，唯一人工干预是 raise_budget 翻倍到 100M 后续烧至 99.9M——止损通道事实缺位。现存其他保护全部非 token 维度（max_turns / impl_run_budget / daily_run_limit / run_timeout_seconds / infra_breaker），下一个重型 spec 将结构性重演。需要在预算面引入制动机制，但制动强度与自动化边界未定。

## Decision

1. 预算面零自动冻结：任何预算档位（含新增 95% major）的告警均不修改 spec 状态，该边界不因止损需求放松。
2. 制动经由两条既有机制承接：①95% major 档告警经 admin_store.HUMAN_SEVERITIES 进人工处置队列（人工止损入口，recommended_action 固定列收敛复验/冻结止损/raise_budget 三选项）；②judge 判定面在预算近满时主动压缩重跑额度（spec 级剩余次数与轮内派发上限双压缩）——语义是「判定面主动省着用」，冻结仍由计数触顶或人工裁决触发。
3. major 档判定为独立条件，不挂 100% 分支的 elif 链（单轮跳变越过 95% 直达 100% 时同轮补发）；预算告警幂等标志复位集合常量化，raise_budget 遍历常量集复位——人工止损入口不允许跳变静默与翻倍后永久静默。
4. 近满收敛复验（验证子集化，子集=失败 ∪ depends_on 前置链 ∪ 下游）独立配置且缺省关闭：收敛复验减少子集外场景覆盖，是治理取舍而非纯收益，启用是显式项目决策。

## Consequences

预算击穿的最坏情形是 major 告警等待人工处置，而非系统自动止损——人工响应时延是本模型接受的代价。judge 额度压缩只在近满阈值以上生效，未近满路径零行为变化。收敛复验存在子集外回归面，以缺省关闭 + major 档人工处置链兜底，验证报告注明收敛模式与子集范围供裁决回退全量。后续预算相关 SPEC 不得引入预算面自动冻结或缺省启用的自动收敛切换；放松该边界须显式推翻本裁定。
