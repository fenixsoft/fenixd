# ADR-146：改道重派以跨轮失败集对比止损，留存带链内作用域

date: 2026-09-23
status: accepted

## Context

场景缺陷改道重派 judge 修复后重跑仍同批失败时，改道门没有任何跨轮失败集对比，仍按剩余预算继续消耗改道轮次才收口。单纯加跨轮对比又会引入另一类事故：留存记录若无作用域约束，新验证链的首个门触发会读到上一链条的陈旧留存而立即升级，跳过既有的定向重派语义，人工解冻/daemon 重启后的首个门触发即误停。

## Decision

- 止损判据 = 跨轮失败集对比：改道前失败集 ⊆ 重跑失败集（含相等，即纯新增、无一修复）→ 判改道无效，立即升级人工，不消耗剩余改道预算；任一改道前失败场景已不在重跑失败集（有场景被修复）→ 判有效，覆盖留存后继续既有预算通道。只看失败集归属（同批 vs 有修复），不判定场景缺陷真伪（仍由 judge/人工负责）。
- 读取点必须在重入重跑已产生新裁决产物之后的那次门触发；MUST NOT 在同一门调用内「重派前读一次」——彼时读到的必然是改道前旧产物，构成假止损。
- 留存带链内作用域：仅当门触发为改道重入轮（修复深度 ≥ 1）且留存记录轮次与深度匹配才做同批判定；链首触发只写入不判定。留存缺失/损坏/轮次不匹配一律视为无留存保守放行——重验、重启驱动的全新链条不被陈旧留存误停。
- 留存写入失败仅告警不阻断改道；本机制不改变预算与修复深度语义，只提前触发既有升级路径。

## Consequences

- 改道无效的 spec 从「耗尽预算才升级」变为首轮同批即升级，预算损失有界；「错误清单与上轮相同或为其超集即未消费」的既有判据从链内局部变量推广为可跨轮留存的 spec 级机制。
