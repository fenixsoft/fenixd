# Agent 运行时

Agent 运行时。本域能力条目清单如下（能力页由存量回填批次逐步产出，落盘后此处升级为链接）。

## 能力页

- `agent-runner` — agent 进程托管与信号处理
- `agent-runner-modules` — agent runner 模块化结构
- `agent-noninteractive-contract` — agent 非交互运行契约
- `agent-prompt-files` — agent 提示词文件化注入
- `agent-run-params-config` — agent 运行参数配置
- `agent-run-artifacts` — run 产物目录与转录留存
- `agent-llm-isolation` — 按 provider 隔离 LLM 凭据与配置目录
- `agent-shutdown-interrupt` — agent 优雅中断与停机协议
- `agent-tool-call-efficiency` — 工具调用效率治理
- `long-task-foreground-wait` — 长任务前台等待策略
- `subagent-model-availability` — 子代理模型可用性
- `tool-result-stream-detection` — 工具结果流事件识别
- `turn-limit-lifecycle` — 轮次上限与生命周期锚定
- `per-agent-timeout-override` — 按 agent 类型超时覆盖
