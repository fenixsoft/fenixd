# ADR-163：验证夹具以注册表显式字段声明，噪音过滤收窄在缺省聚合面

date: 2026-09-24
status: accepted

## Context

夹具被管项目的 seed 告警是验证数据，经缺省跨项目聚合进入人工告警视野。夹具标识若落项目内 config，聚合时需逐项目额外读配置（多次 IO、目录缺失语义复杂）；若靠路径/名字推导则脆弱不可扩展。项目列表数据源是 overview、运维操作与大量验证场景可见性的共同依赖，整体过滤会连带隐藏夹具。

## Decision

- 夹具标识=监控注册表（dashboard.yaml 项目条目）显式布尔字段：在聚合的唯一数据源上读取零成本、声明式可审计；禁项目内 config 标记、禁路径/名字推导。
- 扫描发现的项目恒非夹具（缺省保守=宁多展示不静默隐藏）；存量条目缺标记由夹具供给脚本在复位时补写（更新语义，防按路径去重跳过）。
- 噪音过滤 MUST 收窄在唯一适用面（告警/运维记录的缺省跨项目聚合分支），禁在共享项目数据源整体过滤；显式点名查询（`?project=`）零改动，验证场景依赖不回归。
- 夹具复位负责验证数据写面清空到空基线（杜绝 seed 跨验证轮次累积），挂在验证 prepare 必经步骤，与 STATE/配置复位同处。

## Consequences

验证噪音不再进入人工告警横幅与消息推送；夹具的可见性、操作能力与依赖它的场景保持完整；新增夹具有标准化登记与复位动作。
