# ADR-031：dashboard 项目运维——tmux 会话启停、忽略列表软删除

date: 2026-09-02
status: accepted

## Context

概览页需要项目级 daemon 启停与移除能力。直接 kill tmux 会话最快但跳过优雅清理，run 产物与状态文件可能半写；「删除项目」若实现为移除显式注册项，自动发现的项目会在下次扫描重现——移除语义对自动发现项目天然失效。

## Decision

- daemon 生命周期以 tmux 会话为唯一载体：启停复用既有会话命名与启动命令；停止先发优雅中断信号并轮询退出（至多数秒），仍未退出才 kill-session 强制兜底；启动幂等（已运行返回 already，不重复拉起）。
- 软删除 = 忽略列表：项目路径追加进 dashboard 配置的 ignored 顶层键，项目发现合并显式注册与目录扫描后统一过滤；忽略优先于显式注册（再次显式注册也被忽略）。
- 软删除不删任何项目文件与数据，显式注册项一并移除避免配置冗余；恢复 = 手工移除忽略条目，UI 不提供恢复入口以防误操作面。
- daemon 状态变化不产生数据文件变更，启停结果经 SSE refresh 通道广播触发前端刷新。

## Consequences

- 优雅优先保证 run 产物与状态文件一致性，强杀只是兜底而非默认路径；「删除自动发现项目」的语义只有忽略列表能满足。
- 被忽略项目保留全部数据，重装/恢复成本为零；忽略列表手工编辑是受支持的恢复方式，需在删除确认文案中给出路径。
