# 守护进程平台

守护进程平台。本域能力条目清单如下（能力页由存量回填批次逐步产出，落盘后此处升级为链接）。

## 能力页

- `daemon-singleton` — daemon 单例保证
- `daemon-health` — daemon 健康监控
- `daemon-watcher-startup` — watcher 启动与 SPEC 播种
- `daemon-drain-integrity` — 排水期完整性保证
- `daemon-error-escalation` — daemon 错误升级上报
- `graceful-restart-drain` — 优雅重启排水窗口
- `supervisor-hosting` — supervisor 托管链
