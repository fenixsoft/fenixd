## ADDED Requirements

### Requirement: 目录契约增补代码锚点段

`knowledge-atlas-directory` 能力页（目录契约真相源）的能力页结构契约 MUST 增补：
能力页可含 `## 代码锚点` 段（主实现/单源符号/消费方/守卫测试四类标签、文件级
粒度禁行号、新页强制存量增量），并登记锚点存活检查的机器校验面（段内路径存在性，
由 audit 车道消费）。契约同时登记退役语义：能力主体删除时其能力页直接删除不
墓碑，域表尾一行退役注记为唯一墓碑形态。

#### Scenario: 契约页可指导新折叠

- **WHEN** 蒸馏 agent 按契约页执行新建能力页
- **THEN** 契约页含锚点段四类标签形态定义与退役即删语义，无需会话外知识

### Requirement: 目录契约增补症状速查段

域导航页 `_domain.md` 可含「症状速查」段：症状签名 → 能力页两列速查表，仅
运维/排查密集域落此段（首个范例落 dashboard-platform 域），非强制全员。

#### Scenario: 症状速查命中

- **WHEN** agent 处理「页面标题被顶栏动作区挤窄」类排查任务
- **THEN** dashboard-platform 或相关域页症状速查表能把症状签名映射到具体能力页
