# 模型网关与配置

模型网关与配置。本域能力条目清单如下（能力页由存量回填批次逐步产出，落盘后此处升级为链接）。

## 能力页

- `llm-model-assignment` — 各 agent 角色的模型分配
- `chain-model-mapping` — 链路模型映射
- `dashboard-chain-editor` — 链模型映射编辑器
- `provider-chain-config` — provider 链配置
- `failover-dispatch` — provider 故障切换派发
- `provider-fault-fuse` — provider 故障熔断
- `provider-transient-backoff` — 瞬时故障退避
- `transient-dispatch-gating` — 瞬时故障派发门控
- `transient-controls-ui` — 瞬时故障控制界面
- `provider-circuit-observability` — 熔断状态可观测
- `model-billing-config` — 模型计费单价配置
- `provider-billing-config` — provider 计费配置
- `model-chain-health-probe` — 模型链健康探测
- `hierarchical-config` — 配置分级（用户级+项目级合并）
- `hot-reload-unknown-key-tolerance` — 配置热更新未知键容错
- `config-tabs` — 配置页页签
- `settings-system-tab` — 设置页系统页签
