# ADR-162：run 指标以转录事件为权威源，禁采信网关 modelUsage 金额

date: 2026-09-25
status: accepted

## Context

网关 token 记账实测自相矛盾（同一 run 的 modelUsage 缓存读计费与 result.usage 相差一个量级），金额不可信；而轮数×上下文的 O(N²) 增长结构是转录事实。另实测各网关对 cache_control 接受写入但不产生可复用命中——前缀缓存不可依赖属网关侧结论，框架侧无修复空间。

## Decision

- run 经济性指标（轮数/上下文峰值/input/cache_read）MUST 从本 run 转录事件（assistant 事件数与 message.usage）累计，禁以网关 modelUsage 金额为权威。
- 新指标 MUST 并入既有收尾指标设施（同一调用；日志侧与转录侧字段同名同义），禁让读侧同时理解两套字段语义；估算型指标必须显式标注估算口径。
- 诊断告警 MUST 设最小样本门槛（零轮空跑、维护类 run 不达标只落指标不打告警），防诊断信号淹成噪声；阈值键登记受管白名单并具备设置界面。
- 缓存结论以可复现探针固化（输出 JSON 判据）；当前口径=前缀缓存不可依赖、不做缓存优化，网关升级后以探针复验再议。

## Consequences

上下文成本结构可观测、防回归；优化投入不再被不可信记账误导；告警面维持降噪纪律。
