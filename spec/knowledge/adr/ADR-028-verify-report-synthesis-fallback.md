# ADR-028：人读验证报告由结构化数据确定性合成兜底

date: 2026-09-04
status: accepted

## Context

验证裁决 agent 偶发跳过写人读 Markdown 报告的步骤：结构化结论（场景结论、真实产品 Bug、根因、证据）完整落在 JSON 产物中，下游消费者却拿不到报告，只能自行重新诊断。重跑验证烧钱且裁决可能漂移；一律阻断则让单个 Markdown 文件瘫痪整条验证链。

## Decision

- agent 手写报告优先（含叙述性分析，质量更高）；仅当报告文件缺失时框架介入，以结构化数据确定性合成——纯本地渲染，零额外成本。
- 合成器为共享 helper、单一实现，禁止第二套渲染逻辑；后续任何需要报告的下游一律复用。
- 框架兜底 MUST NOT 覆盖既有文件；兜底合成必发人工告警，使「agent 未遵守产物契约」的劣化信号可见，不被静默吸收。
- 合成失败（结构化数据也不可用）才 fail-closed 阻断 + 告警，与既有验证完成度门禁语义一致。

## Consequences

- 验证链不因人读产物缺失而中断或重跑；报告可信度分层为「agent 手写 > 框架合成」，发生合成即有告警留痕。
- 合成格式以 dashboard 解析器可读为准（章节标记与解析契约对齐）；内容以结构化 JSON 为单一真相，报告是它的投影。
