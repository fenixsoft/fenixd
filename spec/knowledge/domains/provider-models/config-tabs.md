# 配置页页签

配置页按页签组织各配置段，页签状态为纯前端态，保存与报错横跨全部页签生效。

## 规则

- 配置页内容组织为 4 个页签：「LLM Provider」「Agent 模型分配」「并行度设置」「审批模式」，页签与原配置段一一对应（Provider 列表管理 / agent 分配卡片 / 并行度与运行超时字段 / 审批模式单选项）。
- 保存按钮与保存提示文案常驻页签栏下方，不位于任何单一页签内容内。
- 切换页签只隐藏旧内容、显示新内容：全部表单状态（输入、勾选、单选、provider 卡片）跨页签保留，不重渲染、不丢数据。
- 保存时序列化全部页签的字段（不只活动页签），合并持久化；配置加载错误或保存失败时，错误/警告横幅在任意活动页签下均可见。
- 页签选择为纯前端 DOM 状态：打开或刷新页面回默认第一页签（LLM Provider）；SSE 推送驱动的刷新不重渲染页面、不重置当前页签，各页签表单输入均保留。
