# 知识候选区（_inbox）

交互会话（Claude Code / dsh / daemon 车道）产出的排查、立项、实现结论的
**仓内回流候选区**：把值得沉淀的知识以自由格式 markdown 投递到这里，由
distill 车道在下一轮蒸馏时折叠进能力页（piggyback，无独立折叠派发形态）。

## 投递契约

- 一个主题一个 `.md` 文件，文件名用小写 kebab-case（如
  `dispatch-stall-root-cause.md`），投递到本目录（`spec/knowledge/_inbox/`）。
- **自由格式**：不要求能力页契约（marker / 150 行硬顶 / 溯源段均不适用），
  校验与 audit 扫描对本目录显式豁免。只求把事情讲清楚，建议包含三段：
  - **背景**：什么场景下遇到的问题 / 做的决策；
  - **结论**：现在生效的规则或事实（这是折叠进能力页的主体）；
  - **证据**：日志、命令输出、复现步骤、相关文件路径等可回查材料。
- 结论写**当前事实**（「X 是 Y」），不要写成变更叙述（「本会话修复了 X」）——
  折叠时只有当前事实能进能力页规则段。

## 折叠语义（distill 车道 piggyback）

- distill 每轮（SPEC push 终态触发）在蒸馏当轮 SPEC **之前**先逐条消化本目录
  存量：按能力页契约折叠进相关能力页（或新建能力页，超 150 行拆主从分片），
  按条目顺序每条独立提交，可中断。
- `_inbox/` 非空**不构成独立派发条件**：安静周（无 SPEC 归档）滞留是设计内
  行为，由 audit 周期轮的积压提醒（≥10 条或最老条目滞留 ≥7 天，落
  `../log.md` lint 行与 dashboard 知识页签积压计数）兜底可见性。
- **折叠成功**：条目移入 `done/`，折叠到的能力页 marker `sources` 追加
  `spec/knowledge/_inbox/done/<条目文件名>`（file 形态，机器校验放行该前缀、
  只查文件真实存在），候选原文永久可考。
- **折叠失败**（实时 `validate_knowledge` 未通过）：该轮不落盘、条目**滞留
  本目录原地**不丢弃，`../log.md` 记失败行，下一轮 distill 自动重试。

## done/ 为溯源永久保留区

`done/` 内是已折叠条目的原文，作能力页 marker sources 的溯源目标，**永久
保留、禁删改**；归档溯源改写器对本目录（含 `done/`）与 `../log.md` 显式
豁免，条目原文逐字节冻结（原文中指向已归档 `spec/changes/<名>` 的历史形态
文本保持原样，静默改写才是真违背承诺）。
