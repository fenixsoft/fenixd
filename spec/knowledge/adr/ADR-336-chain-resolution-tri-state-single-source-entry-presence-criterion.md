# ADR-336：模型链三态判定单源，「有无分配条目」为唯一划界判据

date: 2026-11-08
status: accepted

## Context

「角色没配模型」与「角色配了模型但配置是坏的」此前共享同一运行期结局（链为空、回落默认网关）：回落 WARN 与配置错误不可分辨，配置写错被当成合法的「无分配」静默兜底，派发失败的呈现归因与真实原因脱节。

## Decision

以「角色有无分配条目」为唯一判据划界两形态：无条目 = 无分配（合法回落形态，对称回落 + 一次性 WARN）；有条目但经校验链为空 = 分配失效（配置错误形态，MUST NOT 静默回落，发配置告警并按 `[model-chain-unavailable]` 归因）。链解析三态判定（unassigned / invalid / ok）收为加载侧单一实现，派发侧只消费同一解析结果，禁另立口径。

## Consequences

runner 及后续消费方不得从原始 config 独立重推链状态；判定语义演进只动单源实现。部分条目失效仍走元素级跳过、不判整链失效，避免局部坏名放大成整角色停摆。
