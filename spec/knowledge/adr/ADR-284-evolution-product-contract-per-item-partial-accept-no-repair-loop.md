# ADR-284：进化产物契约拒绝粒度细化到单条部分回收，全非法 fail-closed，不做修复回问回路

date: 2026-10-27
status: accepted

## Context

自进化分析产物契约校验对单条目契约错误（section 越三值枚举等）整份 raise ContractError：合法条目陪葬、下检查点全量重跑（实证一次枚举幻觉致 396 turns 约 $19 白烧，重跑浪费 $27.36 靠自动重试全额自愈）。而输入侧读 todo.md 对未知小节是「跳过+WARNING」宽口径，既有部分恢复语义只覆盖「条目不足」与流式截断 .parts 两态，单条非法无任何中间路径，失败现场产物文件还被清理删除。备选方案「带错误回问修复」需新起小型修复调用；「放宽校验放非法条目入库」则破坏防坏数据底线。

## Decision

输出侧契约校验对齐输入侧宽口径：单条目契约错误收集错误并跳过该条、合法条目照常返回并落库——落库复用既有 partial 语义（run 记失败、水位不推进、下检查点幂等补齐），一次全量重跑降为一次部分重跑。宽口径仅 evolution 落库链路经显式参数启用，read_contract 默认严格口径不变、其他调用方零影响。全部条目非法仍整份拒绝（fail-closed，防大面积跑偏坏数据入库）；文件级错误（产物缺失/坏编码/不可解析/缺 items）不属宽口径豁免面。失败现场产物仅在部分接受路径改名 .failed 同目录留档，全非法路径不扩大留档面。不建「带错误回问修复」回路——检查点自动重试已实测自愈，回问属重复投资。

## Consequences

- 枚举幻觉类浪费从「合法条目陪葬+全量重跑」降为「只重跑被跳过条目」，恢复完全搭既有水位不推进+幂等去重的检查点重试便车，零新增恢复机制。
- 模型大面积跑偏退化为「多条跳过+少量登记」，兜底靠「全非法仍拒绝」与既有条目不足阈值；部分接受不掩盖失败——run 终态仍是失败并出告警，只是不再零产出。
- read_contract 返回形态新增 errors 字段（逐条 index+message），严格口径恒空；返回形态向后兼容是硬约束，后续新增消费方不得绕过显式参数放宽默认口径。
- .failed 留档无自动清理与保留期，随部分接受次数永久累积，清理归外部运维；留档改名失败只降级为无现场，不阻塞部分接受收尾。
