# ADR-302：第二 harness 真实验收人工信号式触发，缺省值翻转禁入自动化路径

date: 2026-10-30
status: accepted

## Context

dsh 通道功能落地后，终态定位是取代 claude 成为主 harness（`agent.harness` 缺省值翻转）。缺省值翻转影响全部车道，一旦误翻（假端点冒烟通过但真实模型行为失真、验收脚本自身缺陷误判），全链 run 以不合格通道代跑。而 agent 侧既无真实模型凭据也无运维权限——把「真实环境验收执行」写成自动化任务必被打回；「验收通过」与「切换缺省」又是两个决策：前者是技术证据，后者是带运维后果的人工裁决。自动化链路天然有把两步合并执行的压力（验收脚本顺手翻配置）。

## Decision

- **真实全链验收人工信号式触发**：真实环境验收的执行请求落位 `.fenix/todo.md` 人工队列（restart_request 信号范式），agent 侧只完成落位与预演自检（凭据存在性、健康检查、dry-run 计划），实际执行由用户发起；任何自动化路径（验收脚本、回归、自进化链）MUST NOT 发起真实模型调用的验收执行。
- **缺省值翻转永不自动化**：`agent.harness` 缺省值翻转 MUST NOT 出现在任何自动化路径中；验收报告以「假端点证据」与「真实证据」分栏呈现，翻转决策只认真实环境证据，由用户依报告（含决策申请段）裁决；裁决通过后由一次性微变更执行（config 缺省翻转 + ADR-271 补记），执行体不得夹带其他变更。
- **验收证据以既有机制产物为唯一真相源**：run jsonl、投影可观测性计数、`.fenix-run-result.json` 硬门、run_metrics——验收基建只收集与比对，禁另造证据格式；验收脚本失败 fail-loud，禁产出「假绿」报告。

## Consequences

- 误翻转风险结构性归零：即使 dsh 通道全部假端点冒烟绿，缺省通道在用户裁决前恒为 claude；代价是翻转时点受人工节奏约束，不追求无人值守换代。
- 「换缺省即换主通道」类决策（未来第三 harness、回切 claude）同受此门约束——自动化链路可以验证、可以建议，不能执行缺省切换。
- 验收基建的可信度依赖证据单源与 fail-loud 纪律：一旦出现「脚本自带判定即证据」的旁路，本 ADR 的分栏约束失效，须显式 supersede。
