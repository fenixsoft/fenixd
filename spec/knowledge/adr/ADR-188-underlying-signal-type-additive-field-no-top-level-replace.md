# ADR-188：包装通道透传底层信号类型——独立附加字段，禁顶层类型替换

date: 2026-09-28
status: accepted

## Context

手动唤起通道消费请求文件时曾硬编码顶层 signal_type 为通用「人工介入」类型，处置收尾的自动复位门（按 signal_type 判定命中集合）因此对底层属自动复位集合的信号永不命中——人工处置完还要二次人工复位。顶层类型承载 store 记录、节流锚点、展示分区三重职责，直接替换会与自动检测通道互相吞并。

## Decision

- 通用通道包装具体信号时，底层类型必须以独立附加字段透传（缺省 None），MUST NOT 替换顶层类型——顶层类型的多重职责（记账/节流/展示）不动，复位门扩展一处即生效，其余零回归。
- 底层类型发现用消费侧反查（读信号 store 未处置记录、created 取最新一条），禁要求写入口带参（两条入口都要改且旧格式请求文件兼容期行为含糊）；反查必须排除通道自产记录——否则下次唤起会把上一次手动信号反查成底层类型，复位门永不命中。
- 消费判定门在判定点单点扩展（顶层或底层字段任一命中），独立复位路径不动；字段写入处注释语义与消费点清单，防未来消费点误读。
- 陈旧反查的兜底 = 只查未处置记录 + 取最新一条 + 复位路径自身状态守卫（对非预期状态的 spec 返回 None，误反查至多 no-op，不会错误复位）。

## Consequences

- 跨通道归因与自动复位可在不动顶层协议的前提下扩展；新增包装通道时「底层类型如何透传」是必答项。
