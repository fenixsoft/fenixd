# v3 运维记录页（activities-page）

## ADDED Requirements

### Requirement: 跨项目聚合视图

`/activities` 页面通过 `GET /api/admin-activities` 拉取跨项目分组聚合数据（响应含 `projects` 分组数组，每组含 `name` 与 `activities`），展示全部项目的 Administrator 处置记录；页面标题"运维记录"，副标题"跨项目 Administrator 活动"（语义同 v1）。

#### Scenario: 打开运维记录页

- **WHEN** 用户点击 v3 左侧菜单「运维记录」进入 `/activities`
- **THEN** 页面展示项目页签栏与各项目处置记录卡片，页面不出现"建设中"占位内容

#### Scenario: 页签条数徽标

- **WHEN** 聚合数据返回多项目记录
- **THEN** 每个页签（含"全部"）展示该分组记录条数徽标，"全部"页签条数为各项目之和

### Requirement: 页签切换

页签支持「全部」与单项目两种视图："全部"按项目分段展示（每段标题含项目名与该段条数），单项目页签仅展示该项目的记录列表；当前选中的项目从数据中消失时自动回退"全部"。页签选中状态跨刷新保持（v1 行为：模块级状态）。

#### Scenario: 切到单项目页签

- **WHEN** 用户点击某项目页签
- **THEN** 仅展示该项目的处置记录；若该项目无记录展示"暂无运维记录"空态

#### Scenario: 刷新后保持选中

- **WHEN** 用户停留在某项目页签并触发页面数据刷新
- **THEN** 页签选中状态保持不变（除非该项目已消失）

### Requirement: 处置记录展示

处置记录按时间线样式展示（未处理升级置顶高亮），每条记录至少呈现：项目、时间、处置结果/摘要等 v1 卡片元信息；数据为空时展示"暂无运维记录"空态。实现控件由实现方探索（建议 antd Timeline / Card / Tag 组合），但未处理置顶高亮的语义必须保留。

#### Scenario: 未处理升级置顶

- **WHEN** 某项目存在未处理的升级告警记录
- **THEN** 该记录在分组内置顶且视觉高亮（语义同 v1 "未处理升级置顶高亮"）

#### Scenario: 空数据空态

- **WHEN** 所有项目均无处置记录
- **THEN** 页面各分组或页签内容区展示"暂无运维记录"空态而非空白
