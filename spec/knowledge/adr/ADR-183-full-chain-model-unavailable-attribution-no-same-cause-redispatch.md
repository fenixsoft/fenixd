# ADR-183：链尾模型全不可用是独立归因——禁同因重派循环，切换不递增瞬断计数

date: 2026-09-28
status: accepted

## Context

拒模型错误（unrecognized_model）已被归为切换类错误驱动候选链前进 + 切换冷却，但冷却到期即复位优先、run 失败归因不含「全链模型不可用」语义，派发器按既有同因重派继续——每 2-5 分钟（≈冷却周期）重派再撞同一拒模型条目：48 小时内 22 个实现 run 秒死，单一 SPEC 一晚烧 12 个。

## Decision

- 拒模型识别沿用既有切换类判别机制，禁新造平行切换路径。增量义务有三：①识别命中即记 WARNING（含 provider/model/run_id，供链摘除决策）；②候选链尾模型仍被拒时，失败归因必须含「全链模型不可用」语义，派发器 MUST NOT 对该归因走同因重派——这是阻断冷却周期重撞循环的关键；③链内切换不递增瞬断熔断与同因重派计数。
- 边界分工：切换冷却管 run 内候选链前进；全链耗尽归因管跨 run 重派决策——两者语义不同，禁混用同一计数。
- 链卫生分工：配置模板确认无活动拒模型组合并加警示注释；运行时链摘除是人工运维步骤（运维文档 + todo 登记），不进 SPEC 任务门禁——agent 在 worktree 内改不到运行时配置生效副本、也无主树写授权。
- 不做派发前主动模型探测：拒模型是 provider 明确返回的结构化类别，事后识别零成本；主动 probe 每次多一 round-trip，成本延迟不划算。

## Consequences

- 误判后果有限：把其他错误当拒模型至多跳过一个本可用模型，链上仍有备选可恢复；根治靠链摘除（人工）与归因拦截（自动）组合。
