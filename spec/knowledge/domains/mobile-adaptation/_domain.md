# 移动端适配

移动端适配。本域能力条目清单如下（能力页由存量回填批次逐步产出，落盘后此处升级为链接）。

## 能力页

- `mobile-breakpoint-unification` — 移动断点统一
- `mobile-overview-density` — 总览页移动端密度
- `mobile-detail-header-density` — 详情页头部密度
- `mobile-touch-targets` — 触控目标尺寸
- `mobile-activities-disclosure` — 移动端活动信息展开
- `hook-tables-mobile-adaptation` — 钩子表格移动端适配
