# ADR-367：孤儿处置生效核查代际感知——读侧推进轨迹证据替代 STATE 单源快照

date: 2026-11-16
status: accepted

## Context

处置组终态后的生效核查若只看 spec 当前状态快照，会把「处置已生效、其后被新一轮验证合法前移再冻结」误判为处置未生效——假告警直链仲裁调查，同文案误判多次复发。反过来，在 STATE 写入侧新增水位线字段记录「处置已生效至某代际」需要状态面 schema 变更与迁移成本，且处置组与 spec 状态之间本无代际关联字段可挂。

## Decision

生效核查的证据模型定为代际感知：以处置组完成时刻（组内最新记录 created，处置记录无独立终态时间字段）为代际锚点，在其后检索状态推进留痕日志（fenixd.log 及轮转备份；`Transition:` / `Gate transition:` 两族成功行、from→to 属合法迁移、spec 名精确锚定、channel 不限）作为读侧证据，任一命中即判「已生效、被新代际取代」并做消解簿记（旧组转记消解、关联信号收口、新代际条目以独立类型键落账回链）。STATE 当前状态快照不得作为生效核查的唯一证据源；轨迹匹配谓词按本契约独立定义，不逐字复用解冻族匹配（其 blocked 锚定与 channel 过滤恰会漏掉决定性轨迹行）。日志窗口缺失或无轨迹命中时维持 fail-closed 升级人工，行为零变化。

## Consequences

不新增任何 STATE 写入面与 schema 迁移；轨迹核查只挂 frozen 判 False 分支、已推进 spec 不入扫描，成本与既有日志家族扫描同量级。代价：轨迹证据依赖日志轮转窗口覆盖，更旧处置组不可考时只能 fail-closed（宁误报不漏报）；轨迹读面与解冻族共享但匹配谓词各自独立，两处前缀契约须分别维护。
