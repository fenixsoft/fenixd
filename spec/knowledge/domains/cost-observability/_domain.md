# 成本与可观测

成本与可观测。本域能力条目清单如下（能力页由存量回填批次逐步产出，落盘后此处升级为链接）。

## 能力页

- `cost-observability` — 成本观测与呈现
- `cost-governance` — 成本治理（基础设施故障预算豁免等）
- `agent-cost-control` — agent 成本控制手段
- `agent-run-token-economy` — token 经济性与用量治理
- `run-latency-observability` — run 延迟观测（直方图/瓶颈定位）
- `run-progress-observability` — run 进度观测
- `run-duration-parsing` — run 耗时解析
- `spec-duration-persistence` — SPEC 耗时持久化
- `run-stream-noise-reduction` — run 记录降噪
- `run-stream-thinking-and-scope` — 思考与范围事件呈现
- `run-stream-tool-grouping` — 工具调用分组呈现
- `run-artifact-retention` — run 产物保留策略
- `observability-gaps` — 可观测缺口补齐
