# ADR-149：台账核销只由全量快照观测驱动，局部观测只增不核销

date: 2026-09-24
status: accepted

## Context

周期审查类台账若按「本轮没再看到」就置已解决，窗口型观测（只看本周期变更文件）会把窗口外仍然存在的问题误核销——观测范围小于台账全集时，「未观测」与「已修复」不可区分。

## Decision

- 核销必须由覆盖台账全集的全量快照观测驱动：全仓观测是权威快照，本轮未再观测到的 open 项置 resolved；窗口观测/局部观测未观测 ≠ 已修复，只增不核销。核销语义只绑定全量观测形态，观测范围由触发形态显式区分（全仓=手动，窗口=周期缺省）。
- manifest 为空的观测 MUST NOT 记为「全绿」：显式置空跑状态或跳过并告警，禁入空集白洗通道。
- 待审清单由框架在派发前算定并作为进度分母的权威来源，agent 逐文件增量落盘——进度真实、取消后部分结果不丢。
- 周期窗口与同节拍的既有周期任务同源（读同一 last_run_at 状态源保证窗口一致不漂移），本车道检查点 MUST 排在会覆写该状态源的检查点之前，防窗口退化为空集每日空转；防重状态独立立档，MUST NOT 复用会被同轮覆写的字段。
- ingest 只消费结构化字段（指纹、类别、处置登记），不回流原始转录文本进下游提示词（防 agent 输出夹带指令注入下游）。

## Consequences

- 台账 open 集合的收敛语义可信：resolved 必然来自一次真实全量确认；窗口审查只承担「发现」职责。
