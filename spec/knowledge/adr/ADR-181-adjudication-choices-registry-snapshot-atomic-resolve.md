# ADR-181：人工裁决选择题化——静态注册表、告警内快照、resolve 单端点原子编排

date: 2026-09-28
status: accepted

## Context

对全部真实人工裁决的复盘表明裁决本质是选择题（继续修/人工修完重验/接受现状推进/撤销/知情），但告警只有查看/清除/唤起三个动作，真正的裁决须人工登录会话手改 STATE.md。缺口有三：告警与动作缺关联、裁决动词缺失、Administrator 与人工裁决不共用同一空间。

## Decision

- 裁决选项以静态注册表为共同事实源（Administrator 契约与前端渲染同源），信号发射点只引用注册表，禁告警内联硬编码（三处漂移）。
- choices 在写告警时快照进记录：告警是历史事实，注册表演进不得改写历史告警的选项集；resolve 校验以记录内 choices 为准，缺失回退注册表。
- 动作执行 + 状态推进 + handled + 留痕必须在 resolve 单端点一次完成——前端多次调用无原子性，中途失败产生「解冻了但没推进」的中间态。
- 豁免推进走状态机合法推进路径，禁绕过状态机直写 STATE；目标不可达走显式豁免通道并强制「人工豁免」留痕；不可逆选项前端二次确认；删除运行时文件按 spec 名精确匹配，禁通配清理（僵尸实例误删真实项目数据事故教训）。
- 信号分诊纪律：知情/自愈类不出选择题只出「知道了」；机制类缺口归机制治理，选择题只承载真裁决。

## Consequences

- 存量告警无 choices 字段按无选项渲染（兼容读取）；人工裁决不再依赖登录会话手改 STATE.md。
