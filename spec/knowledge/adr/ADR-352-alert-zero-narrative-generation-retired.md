# ADR-352：告警零叙事生成定调，调查叙事生成链整体退役

date: 2026-11-12
status: accepted

## Context

ADR-242 确立转人工裁决叙事挂告警写入口作纯增强字段，ADR-259 修订为零阻塞异步侧车补写（终态侧车防假态 + 连续失败熔断）。运行下来生成链持续带来延迟、token 成本与「调查生成中」悬挂态，而告警的结构化机械文案（description/evidence/recommended_action/choices/trigger）在实践中已自足支撑人工裁决——LLM 叙事属可退役的成本负担而非决策必需品。用户定调：告警不再触发任何调查叙事生成。

## Decision

告警叙事生成链整体退役：全部发射点（汇聚咽喉 `_send_human_escalation_alert` 与 mergeback、token_budget 旁路点）零后台叙事派发、零 LLM 调用、零侧车新写；生成实现（按 signal_type 证据采集、四段结构、连续失败熔断器、后台补叙线程）随模块删除，MUST NOT 重建；配置三键退役且 loader 容忍存量 config 残留键；新告警 MUST NOT 出现 narrative 字段、不渲染任何生成中/pending 态。取代 ADR-242（写入口叙事挂点）与 ADR-259（机械文案即时落盘 + 侧车异步补写形态）的生成机制裁定。历史资产读侧保留：退役前侧车报告与 arbiter 车道写入的调查报告按 alert_id 读侧合并渲染（纯可读性增强、零机器语义），告警清理级联删除侧车的责任保留。

## Consequences

- 告警发射链路结构性零 LLM 依赖：成本与延迟负担消除，「调查生成中」类悬挂态随之消失； arbiter 自主处置车道及其调查报告写入不受影响。
- 机械文案成为裁决唯一信息面，告警发射点的文案质量要求上升；叙事失败兜底、熔断、重试预算等失败面整体消失。
- 历史侧车目录成为只读遗留资产：读侧合并保证历史报告继续可读，不再新增；无迁移与清理需求。
- 让位判定（链头派发 vs 直达人工队列）与叙事解耦迁至 escalation 链路就近，叙事模块不再是判定载体。
- 未来若重新引入告警 LLM 增强内容，必须以新 ADR 论证并显式推翻本裁定，不得以「ADR-242/259 边界延续」为由静默恢复生成链。
