# specs/self-review-timeseries-discipline/spec.md

## R1 聚合断言必须回源

自省条目凡含时序聚合断言（连续 N 晚/逐晚上行/回落/钉值/下界/合计/均值），落笔前必须逐项回源当晚原始汇总行（daemon 日志 run_metrics/延迟汇总行）或归档档案重算；断言句内必须同附每晚原始数字与口径（整晚总量还是单车道分量）。

## R2 转引必须重源

引用前轮条目中的数字视为转引：必须重新回源当晚原始数据，不得沿用前轮条目文本，不得以单车道分量充当整晚总量。

## R3 回源不能时降级

无法回源的聚合断言必须降级为定性描述或显式标注「未核实」，不得保留数值断言原样落笔。

## R4 条款落位

本纪律与既有证据边界归因条款（agents/self-review.md:24 附近）同区并列，同为自省写作前置检查项。
