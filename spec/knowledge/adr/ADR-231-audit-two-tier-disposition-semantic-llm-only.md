# ADR-231：audit 病灶两级处置——机械项脚本直修、语义项禁脚本改写必走 LLM 转写

date: 2026-10-05
status: accepted

## Context

真相源 audit 要处置五类病灶，其中悬空链接、格式违规是机械可判项；规则矛盾、跨页重复则需语义判断。若让脚本按初筛判定直接改写语义类病灶（删改某一侧陈述），会把「初筛的猜测」固化为「真相源的结论」：初筛误判即静默篡改真相源，且无人复核。反过来，若一切都转 LLM 处置，悬空行这类零风险机械项也要烧 run，体检成本不可控。

## Decision

- audit 病灶处置分两级：机械可判项（悬空溯源行删除、格式违规、行数硬顶超标报告）由确定性脚本自动修复并 pathspec 限定提交；语义类（矛盾、重复）禁止脚本改写，必须转定向蒸馏 run——给两处冲突上下文，按增量蒸馏契约由 LLM 重写受影响页。
- 初筛宁松勿紧：脚本初筛只做召回，误报交由转写 run 的 LLM 终判（可直接判「无矛盾」零改动收场）；漏报由下一轮体检自然补上。
- 语义处置的产出回到 ADR-230 的单门：同一契约重写、同一校验、pathspec 提交。

## Consequences

- 真相源语义永不因脚本误判被静默篡改；机械项处置零 LLM 成本。
- 代价：初筛误报消耗转写 run（单个 run 成本，可接受）；语义项处置延迟一个 run 转次。
- 后续给 audit 增加新病灶类别时必须先归入两级之一；新的语义类判据不得下沉为脚本直修。
