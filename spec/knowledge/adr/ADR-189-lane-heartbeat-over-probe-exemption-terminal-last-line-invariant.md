# ADR-189：车道活性心跳优先于探针豁免——豁免会遮蔽重启后的真孤儿，终态末行后置不变量

date: 2026-09-28
status: accepted

## Context

框架侧并行车道采用最小生命周期 run 形态（只在启动与终态各写一批事件、不经通用 runner）：孤儿/无驱动探针的「run 转录 mtime 宽限」判据在车道静默审查期恒误真，长审查（63 文件 +6694 行，15 分钟）即被误报成条、唤起 admin 空转。而把「车道停等」当有意等待加豁免的方案被否：停等标记无 boot 恢复——daemon 在停等中重启后，spec 的自愈恰依赖同一孤儿探针直通道，豁免会把重启后的真孤儿永久遮蔽。

## Decision

- 长寿命框架车道（不经通用 runner、run 流只写首尾）运行期必须发心跳：间隔显著小于探针宽限，经既有 run 事件写入口追加非终态进度事件，使「最近活动」判据持续为假。治理探针误报优先补活性信号，禁新增探针豁免路径——豁免字段若无 boot 恢复，遮蔽重启后真孤儿的代价高于误报本身。
- 否决替代方案留档：进程识别补全（pgrep 看不到 env/cwd，需 /proc 遍历，平台耦合脆弱）、引擎内存登记表（重启后清空与 STATE 残留的组合态需另处理，跨模块耦合）。
- 停跳顺序固定：子进程返回（含硬超时）→ 停跳位 + 有界 join → 写终态事件 → 一切清理（归档/worktree）。保证「终态事件末行后置」不变量（ADR-134 的存活判据依赖末行）与无写竞态（心跳线程死亡后主线程独占写）；停跳先于归档防写到旧路径复活文件。
- 心跳事件类型不得进入任何终态映射表（各终态分类器加回归钉，防未来悄悄把心跳当终态）；渲染层对未知事件类型的容忍按既有 fail-open 兜底；心跳写失败静默（观测通道），不影响车道收尾。
- 探针判定函数与 run 终态分类器行为零改动——修复落在车道侧补信号，不动判定侧。

## Consequences

- 附带收益：时间轴/运行记录在车道运行期 mtime 活跃（时长实时、元数据缓存按 mtime 自然重算），为进度可见性留了数据源；心跳粒度粗，标注为约数、不造数。
