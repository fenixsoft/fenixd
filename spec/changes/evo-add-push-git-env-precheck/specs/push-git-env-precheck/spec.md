# 能力规格：推送步骤无远程环境预检短路

## 概述

规范 pm_engine 发布推送与 done 态续推通道在 git 环境不满足时的行为：预检、短路留痕、审批门、配置分级。

## 行为规格

1. 预检：执行 git push 前必须确认存在 remote 与目标分支；任一缺失时推送不执行。
2. 短路留痕：预检不通过时推送结果标记为 N/A 并留痕（push=N/A），不进入退避重试、不写 error 字段、不计入重试计数。
3. 审批门：gates.approve_mode=manual 的项目，done 态续推通道不得自动补投推送（与既有 done 时点判定语义一致）；approve_mode 未配置为 manual 的项目行为不变。
4. 分支解析：推送目标分支优先取配置（新键或既有项目配置），缺省按仓库当前分支探测，不再硬编码 main。
5. 配置分级：pm.push.retry_backoff_seconds 缺失→静默用默认 [300, 900]；存在但类型/长度非法→保留 WARNING 回退默认。
6. 短路幂等：N/A 结果稳定可重复，daemon 重启后对同一 done spec 不再产生新的失败记录。

## 验收

- 无 remote 仓库推送零执行、零 error 写入、零退避计账。
- manual 项目重启后无自动补推。
- 非 main 分支仓库推送目标正确。
- 缺键项目不再出现回退告警，非法键仍告警。
