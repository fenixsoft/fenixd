# 自省与自进化

自省与自进化。本域能力条目清单如下（能力页由存量回填批次逐步产出，落盘后此处升级为链接）。

## 能力页

- `self-evolution` — 自进化车道（改进项起草立项）
- `daily-self-review` — 每日自省调度与增量窗口
- `self-review` — 自省结果分类
- `self-review-run-semantics` — 自省 run 语义
- `self-review-window-snapshot` — 自省窗口快照
- `architect-agent` — 架构师 agent（DFX 评估与重构建议）
- `suggested-improvements-ui` — 改进建议呈现
- `stale-code-selfheal` — 陈旧代码自愈
- `stale-selfheal-cooldown` — 自愈重启冷却
