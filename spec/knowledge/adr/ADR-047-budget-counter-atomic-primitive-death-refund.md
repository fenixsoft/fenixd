# ADR-047：预算计数单点原子原语，死亡豁免走补偿回退

date: 2026-09-07
status: accepted

## Context

预算闸门在 worker 启动处 +1。两个实证缺陷：网关死亡 run（无收工结果）照常计数，真实产出 run 反被冻结；「读 STATE → +1 → 写回」为非原子序列，恢复扫描并发时增量丢失（日志实证同值连续出现两次）。

## Decision

- 计数点保持单一（启动处 +1），死亡判定点做补偿回退（`used = max(0, used - 1)`），不在启动处预判生死；正常失败仍计数的既有语义不变。
- 有状态计数的读改写收敛到 state_machine 的锁内原子原语（锁内读改写 + 回读校验，不匹配重试一次），计数点与豁免点统一走该原语，回退下限 0；禁止在各处散落「读-改-写」。
- 豁免次数记侧车，超阈值触发一次性幂等告警；豁免不设上限，由阈值告警与 token 预算告警双通道兜底。
- 对账为日志级：计数与实际正常收工 run 数偏差记 WARNING，不自动改数。

## Consequences

- 后续任何新增计数语义必须复用锁内原子原语，并发增量丢失一类缺陷不再按点位逐个修复。
- 豁免依赖死亡判定（恢复链路「无收工结果」结论），误判为正常失败时豁免不生效——与既有死亡检测同源，风险不新增；死亡循环仍会烧 token，靠告警人工介入。
