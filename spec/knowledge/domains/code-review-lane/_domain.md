# 代码审查

代码审查。本域能力条目清单如下（能力页由存量回填批次逐步产出，落盘后此处升级为链接）。

## 能力页

- `code-review-agent` — 代码审查 agent 与范围配置
- `code-review-items` — 审查发现台账（items.jsonl）
- `code-review-quality-tab` — 审查质量页签
- `code-review-spec-generation` — 审查发现转修复 SPEC 生成
- `impl-code-review-gate` — 实现期代码审查门
- `impl-code-review-setting` — 实现期审查门配置
- `impl-code-review-tuning` — 实现期审查门调优
- `impl-code-review-writepath` — 实现期审查结果写路径
- `impl-code-review-gate-readback` — 实现期审查门读回校验
- `impl-ocr-parallel-lane` — 实现期 OCR 并行评审车道
- `impl-ocr-join-gate` — OCR 车道 testing 出口 join 门
- `ocr-lane-liveness-heartbeat` — OCR 车道活性心跳
- `timeline-ocr-lane-visibility` — 时间轴 OCR 车道可见性
