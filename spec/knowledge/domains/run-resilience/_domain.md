# 运行守护与失败韧性

运行守护与失败韧性。本域能力条目清单如下（能力页由存量回填批次逐步产出，落盘后此处升级为链接）。

## 能力页

- `agent-run-timeout-supervision` — agent run 超时监督
- `timeout-supervision` — 超时监督配置一致性
- `hang-discrimination` — 挂起与慢速判别
- `run-failure-classification` — run 失败三级分类与熔断冷却
- `run-failure-judgment` — run 失败判定（产物优先）
- `error-attribution-denoise` — 错误归因降噪
- `fail-counter-budget` — 失败计数预算
- `per-spec-impl-budget` — 单 SPEC 实现预算
- `run-budget-continuity` — run 预算连续性
- `verify-recovery-budget` — 验证恢复预算豁免
- `run-cancel` — run 取消
- `run-superseded-terminal` — 被取代 run 的终态标记
- `runtime-run-sweep` — 运行时 run 清扫
- `redispatch-loop-governance` — 重派循环治理
- `redispatch-artifact-succession` — 重派产物接续
- `honest-exit-convergence` — 诚实退出收敛
- `shared-result-file-integrity` — 共享结果文件完整性
- `stale-verdict-race-guard` — 陈旧裁决竞态守卫
- `done-push-dedup` — done 推送去重
- `state-transition-idempotency` — 状态迁移幂等
- `state-write-atomicity` — 状态写入原子性
- `stuck-timeout-single-source` — stuck 阈值单源
- `orphaned-state-signal` — 孤儿状态信号
- `baseline-blocked-gate` — 回归基线失败挂起门
- `lifecycle-hygiene` — run 生命周期卫生
- `cli-retry-backoff` — CLI 退避重试
