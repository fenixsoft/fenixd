# specs/verify-evidence-tiered-retention/spec.md

## 能力

验证证据按体积/类型分级留存：契约声明阈值，超阈值二进制以哈希与登记信息替代入库。

## 需求

### R1 契约分级字段

verify 契约模板新增可选字段 evidence_retention.max_binary_bytes：
- 缺省 10485760（10MB）；
- 缺失或非法值时回退缺省，不阻断契约加载；
- 解析结果供落位指引渲染消费。

### R2 落位指引分级条款

证据落位指引文本（prompt 注入段）包含分级规则：
- 文本/JSON/哈希/小日志直接入库；
- 超过契约阈值的二进制不入 git，落 sha256 sidecar、复现命令与存放路径登记文件；
- 阈值随契约声明联动（缺省 10MB）。

## 验收

- 契约加载对 max_binary_bytes 的三态行为（生效/回退/缺省）有测试钉住。
- 落位指引在契约声明与缺省两种形态下均渲染分级条款，有测试钉住。
