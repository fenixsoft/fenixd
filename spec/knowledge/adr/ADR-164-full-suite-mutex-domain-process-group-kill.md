# ADR-164：同主机全量套件第二发起者必须共入既有互斥域，硬超时按进程组中止

date: 2026-09-25
status: accepted

## Context

implementer 收尾在 run 内跑主机级全量套件，并以主机级 fcntl 锁声明「同一主机全量套件串行」；周期回归车道作为第二个全量套件发起者若另起一把锁，两套完整测试并发争 CPU/磁盘、互相污染工作区产物并拉长双方耗时。回归命令允许 shell 字符串形态，直接子进程是 shell，测试进程是其孙代。

## Decision

- 新增任何全量套件发起者 MUST 抢占既有同一把主机级锁（共入同一互斥域），禁另起新锁；拿不到锁=放弃本次并留痕（顺延到下一周期），禁无限等待。
- 硬超时中止 MUST 杀整个进程组（以新会话 spawn）：只杀直接子进程会留下测试进程森林存活——回归名存实亡、工作区被继续写、产物锁被无名进程占住。
- 跨语言结果格式单一 JUnit XML（框架只维护一个解析器，宽松吸收各框架形态差异）；声明非法 format 值=整段按未配置处理并 WARNING，禁静默按缺省格式解析（必然产出无解释的 parse_error）。
- 周期任务的防重状态独立落盘，禁复用其它周期任务的状态文件（会互相覆盖、防重失效）。

## Consequences

全量套件在全主机范围串行、资源与工作区不被并发套件污染；超时无残留进程森林；结果解析单一格式、非法声明显式可见。
