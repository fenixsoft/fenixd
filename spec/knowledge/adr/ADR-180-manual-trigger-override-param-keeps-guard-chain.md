# ADR-180：手动触发=临时授权成参、只放宽调度门槛、安全守卫链单点保留

date: 2026-09-28
status: accepted

## Context

自动车道只有后台激活路径，用户无法「现在就跑一批」。跨进程直调编排器不可行（dashboard 与 daemon 分进程，ADR-100 边界），而绕开编排器复制一份守卫链、或消费端临时改配置开关，都会让守卫语义出现第二份真相并被未来调用点滥用成「随手绕开关」。

## Decision

- 手动触发复用编排器单一入口，临时授权以显式命名参数表达（缺省关闭）；既有调用点不传参、行为零变化。禁消费端改配置、禁旁路入口复制守卫链。
- 临时授权只授权「不等调度」，不授权「跳过安全链」：失败保留、契约 fail-closed、单飞守卫在 override 下照常生效。
- 触发沿既有文件信号族（O_EXCL 原子独占创建防并发覆盖丢触发），daemon 主循环消费，先读后删、读删失败跳过本轮。
- 判定结果以结果文件回链：无论触发与否都落结构化结果（触发与否/原因/文案/时间戳）；写入新请求前预删旧结果 + 请求时间戳一致性校验，双重防御陈旧结果被误当本次反馈；拒绝类原因→文案映射收敛在消费端一处，前端只渲染 message。
- 依赖组件未装配时不静默：落明确原因的结果文件让用户可见。

## Consequences

- 参数名显式表意 + 仅信号消费函数调用，防未来调用点误用；无条目时手动触发即时拒绝反馈，无排队重试语义；信号/结果文件留盘对旧码零副作用，回滚即还原。
