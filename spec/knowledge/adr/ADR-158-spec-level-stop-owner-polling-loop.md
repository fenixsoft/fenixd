# ADR-158：spec 级停止指令在属主轮询环内进程内判定，跨进程只异步受理

date: 2026-09-25
status: accepted

## Context

在飞 agent 进程只能由属主线程终止（轮询环是唯一能 terminate/grace/kill 的位置，调用线程不做跨线程 kill）。冻结来源不止 dashboard（CLI、admin 处置、恢复链路都写 frozen），为停止新增文件信号需三段接力且覆盖不全。dashboard 与 daemon 是不同进程，在跑 run 登记在 daemon 内存里，跨进程直接终止不可行。

## Decision

- spec 级停止（冻结）MUST 在 `_run_claude` 轮询环内以进程内读 STATE 判定，与取消旗标同点同型；禁为停止类指令新增文件信号通道。
- 轮询环检查顺序：frozen 先于 cancel（spec 级 > run 级），命中 frozen 时清理 cancel 旗标（防解冻续做被残留旗标立即再杀）；`poll()` 已退出的按自然结果收工，冻结不追溯。
- frozen 判定禁引入重试子循环细粒度位置（调用频次从秒级放大到每子循环）；成为热点只允许读侧 TTL 缓存，禁挪判定位置。
- 冻结终止走独立异常+独立终态行：复用取消异常会落取消保持分支，使解冻后被恢复链豁免、与自动续做直接冲突；终态行与取消行同落盘位置（join 后 finally 内）。
- 冻结现场保全走保留登记形态并扩展分支保护判据覆盖冻结态（冻结 spec 是 blocked，不在既有保护集内，遗产宽限回收会删保留分支）；禁落入失败清理路径（会删 worktree 目录）。
- 跨进程删除：异步受理（202+停止计数）→ 文件信号 → daemon 停 agent 等终态（有界）→ 软删除；无在跑 run 时同步直删；托管态前置校验，信号已存在 409。

## Consequences

冻结对在跑 agent ≤1s 轮询粒度+≤10s 宽限生效；冻结与取消语义互不污染、解冻自动续做；删除交互不阻塞浏览器且无跨进程终止歧义。
