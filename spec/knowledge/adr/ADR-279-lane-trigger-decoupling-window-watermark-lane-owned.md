# ADR-279：周期车道触发时点解耦必须配套窗口水位归车道自身

date: 2026-10-15
status: accepted

## Context

多条周期车道（每日自省、周期代码审查、回归）的触发时点同源读 `admin.self_review.run_at`，同刻齐发在账户级打出 provider 429（错误码 1302），结构性削峰要求各车道触发时点可独立配置。但触发时点与增量窗口水位是耦合面：窗口型车道若只挪触发时点、窗口水位仍读共享源（该源会被共享方周期覆写），独立时点晚于共享源时点时，覆写会把窗口下界推进到当日共享时点，「前次审查→共享任务」段的变更滑出所有窗口——静默覆盖缺口，无任何报错信号。

## Decision

- 周期车道触发时点解耦为独立配置键时，其增量窗口水位必须同步改由车道自身状态承载：调度收尾将本轮完成时刻写入车道自有状态文件；共享源水位降级为回退（车道水位缺失时读共享源，再缺失回退固定时长），保证存量与首跑的缺省路径逐位等于解耦前行为。触发时点与水位归位必须成对落地，禁只挪时点。
- 独立键的一切非法取值（键缺失/非字符串/不可解析/越界字面量）一律回退共享源缺省值，巡检不因配置脏值中断（对齐既有 scope 白名单回退口径）；回退解析收口在该车道配置读取器单源完成，检查点不二次解析。
- 「本车道检查点先于会覆写回退水位的检查点执行」的次序约束与触发时点解耦正交，解耦后保留，兜底同轮巡检相遇时的窗口退化。

## Consequences

- 缺省零配置行为逐位不变；配置独立时点后窗口从「共享源节奏」切到「车道自身节奏」（审上次本车道运行之后的变更），语义严格更正确；车道停摆数日时窗口随自身水位拉长，与「窗口=距上次本车道运行」语义一致，首轮回退过渡由回退链吸收。
- 演进 ADR-149 决策中「周期窗口与同节拍任务同源」子句为「车道自有水位+回退共享源」；该 ADR 的核销只由全量观测驱动、空 manifest 禁记全绿等裁定不变。
- 回归车道与自省同槽位问题的后续解耦立项必须复用本模式（独立键+缺省回退+水位归位成对）。
