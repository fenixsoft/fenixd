# ADR-049：agent 提示词文件为唯一真相，动态段归代码，项目附加末尾注入

date: 2026-09-09
status: accepted

## Context

六类 agent prompt 全部为 prompt_builder 内 f-string（千行级），硬编码死段与被管产品领域知识误入框架层；目录里的手写角色 md 无人读取、与现行 prompt 脱节。提示词无用户可设入口，定制只能改框架源码。

## Decision

- 提示词主体迁入 `agents/<agent-type>.md`，文件为唯一真相：路径类变量用占位符并以字符串替换填充（不用 str.format——正文含大量 `{}` JSON 示例）；条件动态段（重规划/断点/error/遗产/冻结/契约/复核/verdict）保持代码生成、按状态追加，文件只承载静态主体。
- 不保留内置副本：文件缺失派发报错，杜绝双真相漂移。
- 项目级附加层：`.fenix/agents/<agent-type>.md` 缺席零注入；存在则以固定标题附加在完整 prompt（通用主体 + 动态段）末尾——附加在末尾不扰动通用指令的注意力权重结构。框架代码路径不写该目录，唯一下写入口是 Dashboard 保存动作。
- 防护为布局级：`.fenix/agents` 经软链解析为通用层目录时读取零注入、写入拒绝。不对任何项目做项目级特殊处理（含框架自身项目——原「项目根 == 框架根即禁用」判定已随状态文件迁移退役）。

## Consequences

- 通用层 = 框架演进，入库走 SPEC；被管项目定制走项目附加层；领域知识（被管产品的校验口径等）归被管项目而非框架。
- 提示词演进有唯一载体，改 prompt 即改文件；动态段与静态主体的边界划错是主要风险面，任何含条件逻辑的内容不得入文件。
