# 缺陷修复

缺陷修复。本域能力条目清单如下（能力页由存量回填批次逐步产出，落盘后此处升级为链接）。

## 能力页

- `code-fix-lane` — 自动修复车道编排
- `code-fix-agent` — code-fix 修复 agent
- `code-fix-config` — code-fix 车道配置
- `code-fix-progress` — 修复进度聚合与呈现
- `code-fix-manual-trigger` — 手工触发修复的 checkpoint 授权
- `correctness` — 代码审查正确性缺陷修复批（CR 台账机械生成）
- `robustness` — 代码审查健壮性缺陷修复批（CR 台账机械生成）
- `robustness-edge-cases` — 边界场景健壮性修复批
- `deferred-findings-fixes` — 审查遗留缺陷修复消化
- `minor-defect-fastlane` — 轻微缺陷快车道
- `inplace-bug-repair` — 验证发现缺陷的原位修复
- `bug-repair-mode-config` — 缺陷修复模式配置
- `repair-commit-enforcement` — 修复必须落提交的强制门
- `repair-lane-dedup` — 修复车道去重
- `fix-chain-regression-inheritance` — 修复链回归继承
- `fix-family-convergence-governor` — 修复族收敛治理
