# 实现车道与交付物

实现车道与交付物。本域能力条目清单如下（能力页由存量回填批次逐步产出，落盘后此处升级为链接）。

## 能力页

- `implementer-task-protocol` — implementer 任务协议与进度登记
- `implementer-deliverable-gate` — 交付物声明硬门
- `impl-tasks-completion-gate` — tasks.md 完成勾选门
- `impl-terminal-nocommit-gate` — 终态零提交拦截门
- `impl-resultfile-contract` — 实现结果文件契约
- `impl-result-selfcheck` — 实现结果自检
- `impl-regression-delegation` — 实现期回归委托
- `impl-wip-checkpoint` — 实现期 WIP 检查点
- `wip-artifact-scope` — WIP 产物范围约定
- `task-artifact-ownership-gate` — 任务产物归属门
- `artifact-path-declaration` — 产物路径声明契约
- `artifact-path-autofill` — 产物路径自动填充
- `artifact-path-dashboard-ui` — 产物路径声明界面
- `deliverable-declaration-triage` — 交付物声明分诊
- `deliverable-declaration-resolution` — 交付物声明解析
- `deliverable-dispute-governance` — 交付物争议治理
- `deliverable-dispute-preclassify` — 交付物争议预分类
- `declaration-premechanize` — 声明机械化前置约束
- `declaration-relocation-protocol` — 交付物声明修正（relocation）协议
- `relocation-writeback-layer` — 修正写回层与读取基准对齐
- `writepoint-semantic-anchor` — 状态写点语义锚定
- `task-progress-sync` — 任务进度同步链路
- `task-progress-writeback` — 任务进度回写
- `tasks-md-tracking` — tasks.md 任务清单跟踪
- `tasks-md-relint` — tasks.md 重 lint 门
- `spec-task-reflow-action` — tasks 任务重排动作
