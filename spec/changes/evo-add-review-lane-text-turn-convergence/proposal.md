# 提案：审查车道纯文本轮输出纪律收敛

## 背景

纯文本轮离群维（无工具调用的模型回复轮，轮数>100 且占比>50%）在 code-review 车道连续两窗命中（code-review-1795190463 为 50.47%、code-review-1795277035 为 58.23%，最新 code-review-1795709077 亦为 50.48%），code-fix 车道多次命中（1795322096 56.45%、1795324297 51.28%，另有 1794656523 60.16%、1795638245 57.55%）。检测机制（2026-11-04-evo-refine-midflight-outlier-dims 交付）与响应机制（evo-text-turn-inflation-response 交付）均已生效，但响应机制的输出纪律按其 proposal 明文只覆盖 planner-plan 车道（「其余车道模板不动」），未覆盖这两个车道机制生效后持续命中无收敛。

实测澄清（2026-11-27）：code-fix 模板并非「无输出纪律」——`agents/code-fix.md:135` 自 2026-09-23（4a2454707）起已有「动作直接执行/收尾只报统计」纪律节，但该形态生效期间车道仍 4 次离群命中，说明既有形态未压住叙述膨胀。因此本 spec 对 code-fix 是「既有节对齐升级到 planner-plan 已验证形态」，不是从无到有新增；对 code-review 才是新增纪律节（该模板仅 :150 有收尾统计约束，无输出纪律标题节）。

## 目标

把 evo-text-turn-inflation-response 已在 planner-plan 车道验证的输出纪律形态（结论与发现先行、压缩逐轮叙述性输出）扩展到 code-review 与 code-fix 两个车道模板，压降纯文本轮占比；同时登记对照基线与止损观察口径，为后续模型版本对照处置留好判据。

## 非目标

- 不改动 planner-plan 车道既有输出纪律（已生效，本窗该车道零命中）。
- 不改动检测机制与阈值（midflight-outlier-screening 原样）。
- 不做模型版本切换或对照试验本身（仅登记止损判据，观察期内占比无压降才转架构处置）。
- 不引入任何输出长度数字上限（agent-prompt-authoring 知识页规则）。
