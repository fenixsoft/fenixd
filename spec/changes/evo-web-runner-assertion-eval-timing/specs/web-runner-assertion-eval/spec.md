# Capability: web-runner-assertion-eval

## Adjudications

### 断言求值时机按类型分层

验证引擎 MUST 按「交互型/流程级」对断言求值时机分层：no_click_interception 等交互型断言 MUST 在其目标步骤的求值窗口内求值（对应步骤完成点即时求值或视图切换感知时机），MUST NOT 与流程级断言一并延迟到全部步骤后统一求值。

- no_console_error 等流程级断言 MUST 保持后置统一求值语义不变。
- 求值时机分层由引擎按断言类型自动判定，MUST NOT 要求场景文件逐场景改动。

### 交互断言失败须附视图快照

交互型断言报 not visible 等失败时，失败载荷 MUST 附求值时刻的页面视图状态快照（当前可见视图、目标元素所在视图、可见性判定依据），使 judge 能区分「元素被遮挡」「元素随视图切走」与「场景真实缺陷」。

- 快照 MUST 为轻量 DOM 摘要形态，MUST NOT 以截图为默认载体。

## Scenario

- 导航进会话视图场景：交互断言在目标步骤求值窗口内求值，不再误报 not visible，真实点击与功能断言结果不受影响。
- 流程级断言：仍后置统一求值，结果与现状一致。
- 目标元素确被遮挡：not visible 失败载荷含视图快照，judge 可归因遮挡。
- 目标元素随视图切走：失败载荷含视图快照明示「元素所在视图非当前视图」，归因明确。
