# ADR-052：STATE.md 字段白名单与终态快照语义

date: 2026-09-09
status: accepted

## Context

STATE.md 是 spec 元数据的持久载体，但序列化只输出固定字段白名单——白名单外字段在下一次 STATE.md 重写时被静默丢弃。同时 run 产物受保留策略清理，对 run 产物实时求和的统计量（如累计耗时）会随清理归零，历史事故中 pushed spec 的耗时被旧代码删产物后永久丢失。

## Decision

- 新增 spec 级字段必须加入序列化白名单才能跨重写存活；可空字段序列化为 null，与既有可空字段表现一致，读取侧据此判「缺字段」。
- 终态统计量在终态转换点单点快照进 STATE（紧随转换成功之后写入，求和口径与读侧展示口径一致）；写入点在编排层，状态机保持对 run 产物零耦合，产物求和放调用侧完成。
- 读取侧优先持久值：仅终态采用快照值（运行中状态忽略冻结值、走实时计算——运行中的量应持续增长）；脏值容错回退实时路径，单字段脏数据不挂接口；存量不回填（产物已丢无从恢复，缺字段回退实时求和）。

## Consequences

- 终态指标不再依赖易失的 run 产物；字段一经冻结，后续产物修复不自动反映显示值（有意取舍）。
- 与 ADR-044 同构：终态量收工/收尾单点采集进 STATE 内部字段，原始明细留在 jsonl/侧车做审计；后续任何「不想丢的 spec 级统计量」都走此模式（白名单 + 终态快照 + 脏值回退）。
