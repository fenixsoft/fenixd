# dashboard-spec-table Spec

## ADDED Requirements

### Requirement: 名称列中文副标题

名称列 SHALL 在 SPEC 英文名主行下方渲染中文标题副标题行（数据源 `/api/specs` 条目 `title` 字段）：副标题为次级视觉（小于主行字号、次级文字色），随主行同级缩进（fix-* 树形子行缩进保持）；条目 `title` 为 null/空时不渲染副标题行（保持既有单行形态）。副标题不承载点击与悬停交互：行点击进详情、名称 Why 悬浮提示（按需拉取 proposal `## Why`）等既有交互行为不变；名称关键字过滤在英文名包含匹配之外 SHALL 同时命中中文标题（大小写不敏感包含匹配，任一命中即保留该行），排序（名称按字典序 = 英文名）与 fix-* 类型过滤语义不变。移动端卡片形态的名称区 SHALL 同规则渲染副标题（次级字号/色，缺失不渲染）。

#### Scenario: 有标题条目渲染副标题

- **WHEN** 列表某条目 `title` 为「知识收件箱回填管线」且名称为 `add-knowledge-inbox-pipeline`
- **THEN** 该行名称列先渲染英文名主行，其下方渲染次级中文副标题行，随树形缩进对齐主行

#### Scenario: 无标题条目保持单行

- **WHEN** 列表某条目 `title` 为 null（存量回填覆盖范围外的 SPEC）
- **THEN** 该行名称列仅渲染英文名主行，无副标题行，布局与改动前一致

#### Scenario: 搜索命中中文标题

- **WHEN** 名称关键字输入「知识收件箱」
- **THEN** `title` 含该关键字的条目保留在过滤结果中（即使英文名不含该关键字）；英文名或标题任一命中即保留

#### Scenario: 排序与树形不受影响

- **WHEN** 列表按名称排序或展开 fix-* 树
- **THEN** 排序键仍为英文名（字典序）、fix-* 挂载与缩进不变，副标题仅跟随主行显示

#### Scenario: 既有交互不变

- **WHEN** 用户点击名称行或悬停名称触发 Why 提示
- **THEN** 行为与改动前一致（进详情 / 按需拉取 Why），副标题文本不触发额外交互
