# 协作图谱大屏

<!-- knowledge: capability=collab-graph-bigscreen-ui rev=1
     sources=spec/archive/2026-10-30-add-collab-graph-bigscreen -->

跨项目「组织画像」IOC 大屏的前端面：8 角色固定就位图谱 + 项目筛选 + 两级下钻，从 overview 枢纽页进入。

## 规则

- **入口与脱壳路由**：overview 页新增「协作图谱大屏」入口（不改现有内容布局语义）；`/overview/collab-graph` 独立路由全屏深色、无 dashboard 框架壳，顶部为大屏标题 + 全局 KPI 条 + 项目筛选器 + 退出按钮（返回 overview）；渲染手写 SVG + React，MUST NOT 引入图表库依赖。
- **角色固定就位布局**：8 个角色节点按 SDLC 阶段固定就位（用户→PMEngine→需求评审→规划→开发→审查/修复→测试/验证→运维→交付方向的确定性布局，无力导向算法）；两次进入同一页面节点位置一致（仅大小/边宽/脉动随数据变化）——跨日汇报可比对。节点大小映射累计成本或时长（实现取一、全屏一致）；在飞角色节点发光脉冲；边宽映射交接次数（weight，同一映射函数下单调）；有交接流动的边有方向指示。
- **项目筛选器**：提供「全部 + 各项目」筛选，切换后图谱与 KPI 重新按该范围聚合；当前选中态可辨识。
- **下钻明细与跨大屏跳转**：点击角色节点或边打开下钻明细面板——列出该角色（或该交接对）最近的 run/交接明细，每条含项目名、SPEC 名、时间、状态（数据由聚合端点内嵌 `recent_runs` 提供，零二次调用）；明细条目提供跳转对应 SPEC 单 SPEC 协作拓扑大屏（`/projects/<name>/<spec>/topology`）的入口；归档 SPEC 条目标注「明细已归档清理」且不可跳转（或跳转后由单 SPEC 大屏降级提示承接）。
- **归档口径注记**：响应 `archived_excluded > 0` 时页面显示口径注记（如「N 个已归档 SPEC 仅计入 KPI，不计入图谱」）。
- **实时刷新**：项目/SPEC 数据变更后重新拉取聚合数据（复用既有 SSE 通道或失效信号），SSE 不可用时至少 30 秒轮询兜底；在飞节点的出现/消失随刷新可见。
- **现有界面零改动红线**：除 overview 页新增入口、路由表与服务层新增条目外，MUST NOT 改动任何现有页面/组件行为与视觉；单 SPEC 大屏与归档链路零改动（overview 页 diff 仅含入口新增）。
