# ADR-141：外部工具凭据注入以 run 级隔离 HOME 为确定性手段

date: 2026-09-23
status: accepted

## Context

外部 LLM 工具的端点解析优先级普遍是「自身配置文件 > 专属环境变量 > 通用网关 env」：用户机器上只要存在该工具的全局配置文件，仅注入环境变量就会被静默压制——调用成功返回但用的是错误 provider，成本记到别处，且洞是静默的。覆写用户全局配置则破坏用户环境，并在并发 run 间互相覆盖。

## Decision

- 需要 run 级确定性选定 provider 的外部工具，凭据注入走 run 级隔离 HOME：在该 run 专属目录落其配置文件，并把 HOME 重定向指向「直接包含该配置目录的那个目录」——指到父目录则工具永远读不到配置，退化为按通用 env 直通的不确定行为。
- 包装器重定向 HOME 后以带 PATH 搜索的 exec 变体替换执行底层工具并透传 argv 与退出码；MUST NOT 用不搜索 PATH 的 exec 变体——裸名可执行文件必然 FileNotFoundError，会把「工具已装」误判成环境不可用而静默降级放行。
- 用户的 baseurl 原样透传，MUST NOT 追加/改写版本后缀：URL 拼接由工具自身负责，框架侧「归一化」会拼出重复后缀的坏 URL。
- 隔离目录按 provider 派生、幂等复用（同 provider 配置逐字节相同、写入幂等），不为每 run 单独建目录造成无界堆积。
- 环境类缺口（工具未装/网关不可达/异常终止）降级放行并要求非空原因留痕，MUST NOT 被当交付物缺口重派烧预算；空原因视为绕过，判失败。

## Consequences

- 与 provider 车道的 CLAUDE_CONFIG_DIR 隔离同族：外部工具集成一律「run 级确定性注入、不触碰用户全局配置、并发互不串扰」。
- 注入不变量须测试钉住（注入目录下配置文件必须存在）；工具上游若给配置路径提供环境变量支持，可退化为更简形式。
