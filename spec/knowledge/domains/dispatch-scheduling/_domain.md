# 调度与派发

调度与派发。本域能力条目清单如下（能力页由存量回填批次逐步产出，落盘后此处升级为链接）。

## 能力页

- `priority-parallel-scheduler` — 严格优先级并行调度
- `parallelism-config` — 并行度配置
- `dispatch-concurrency-tuning` — 派发并发度调优
- `dispatch-queue-aging` — 派发队列老化治理
- `dispatch-dependency-wakeup` — 依赖满足后的派发唤醒
- `scheduling-kick-signal` — 调度踢一脚（kick）信号
- `full-scan-resilience` — 全量扫描兜底恢复
- `spec-event-delivery-integrity` — SPEC 事件投递完整性
