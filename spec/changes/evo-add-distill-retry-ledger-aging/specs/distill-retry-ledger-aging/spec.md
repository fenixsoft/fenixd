# 能力规格：蒸馏重试台账欠账龄期升级与节流

## 概述

规范蒸馏重试台账（knowledge-distill-pending.json 与 todo 勾选项）中未处置欠账的告警行为：龄期展示、超期升级、持久化节流。

## 行为规格

1. 发射条件：维护检查点发现台账存在登记超过 24 小时的未处置欠账时发 knowledge_distill_retry_stale 信号（warning）——现状语义保持。
2. 龄期展示：信号 description/evidence 必须包含欠账条目登记时刻、当前龄期（小时/天）与对应归档 spec 名。
3. 超期升级：同一欠账龄期超过 72 小时仍未处置时，信号升级为 major（或框架既有 ESCALATION 通道），升级态信号同样携带龄期；台账条目处置（勾选/移除）后发射自然停止。
4. 节流语义：同一欠账的重复发射受持久节流窗口约束，窗口期内不重发；节流状态跨 daemon 重启有效，不得依赖进程内存态幂等。
5. 升级穿透节流：龄期跨过 72 小时门槛后的首次发射不被节流吞掉，立即发出升级态信号；其后升级态同样受窗口节流。

## 验收

- 龄期字段存在且与台账登记时刻一致。
- 72 小时边界前后发射级别符合规格。
- daemon 重启后节流窗口内不出现重复发射。
- 升级首射穿透节流窗口。
