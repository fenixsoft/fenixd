# Fenix 帮助中心

欢迎来到 Fenix Loop Engineering Framework 帮助文档。Fenix 是一个通用的 AI 辅助开发框架，通过状态机驱动的 SPEC 生命周期、闭环验证链与多 Agent 协作，把「需求→设计→实现→验证→发布」的全流程自动化：你提出需求，框架自动完成设计、实现与验证，只在最终推送时需要你审批。

本帮助中心按使用场景组织内容。如果你是第一次接触 Fenix，建议从[快速上手](01-quick-start.md)开始，用 5 分钟跑通从初始化到交付的端到端流程，再读[核心概念与架构](02-concepts.md)，理解闭环原理、Agent 角色分工与 full/fast-track 两种执行模式的区别。如果框架已经跑起来，你遇到了 SPEC 卡住、验证失败、告警频发之类的运行问题，可以直接查[FAQ 与故障排查](12-faq.md)按现象定位根因；想系统理解框架靠什么机制保证不出事（声明 lint、晋升门禁、产物硬门、收工守卫、自愈链路与告警分级如何层层设防），读[保障机制](07-safeguards.md)专章；需要追问某条治理规则（预算熔断、重试退避、告警分级）的完整数值口径时，再进[调度与治理规则](06-governance.md)细读。其余各章按主题展开：生命周期与状态机、CLI 操作、验证体系、Dashboard 使用、配置参考、文件与数据地图、日志体系，完整目录见下表。
