# ADR-182：run 内自证复用生产校验体——契约判定责任单点化，禁复制逻辑

date: 2026-09-28
status: accepted

## Context

契约类失败（如处置数组形状不合法被守卫逐条拒）发生时，agent 在 run 内看不到 daemon 侧报错，重试轮照抄坏形状整轮重烧（实测连烧两轮）。同时全量回归双跑：run 内自查手工跑 8-10 分钟，框架侧验证阶段必然再跑一遍。

## Decision

- 契约型产物的 agent 收工自证入口 = 生产校验体的模块级 CLI 出口（同一函数对象，退出码 0/1 语义化、违规明细逐条到 stderr），禁复制校验逻辑到独立 lint 脚本——复制必漂移（键名契约缺口事故教训）。提示词注入「结果文件写完必须先跑自检、非零退出不得收工、按明细修复后重跑至退出码 0」。
- 契约正反例进任务书动态注入段（合法/非法形态逐字对照，覆盖状态枚举与必填键）；静态 agent 模板只放通用原则，禁静态/动态双源漂移。
- 判定责任单点化：验证类判定（全量回归）由框架验证链负责，run 内自查降级为降级路径（仅在确证框架侧产物不可用时执行，无法确证时默认信任验证链）；读侧数据源优先级 = 框架车道产物（带分支指纹）> run 内自查落盘 > pending（fail-open），禁因 run 内自查缺位新增打回门。
- 框架车道产物快照必须 stamp (branch, merge_base, head_commit) 指纹；无指纹的存量快照按不可见处理回退下一优先级，不阻塞。

## Consequences

- daemon 侧硬门原样保留作兜底（自检被忽略最坏回到既有打回路径，不劣化）；省每轮 8-10 分钟回归双跑，代价是 run 内回归反馈延迟一个验证阶段（吞吐优先，权衡记录在案）。
