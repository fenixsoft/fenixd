# 工作树与版本控制

工作树与版本控制。本域能力条目清单如下（能力页由存量回填批次逐步产出，落盘后此处升级为链接）。

## 能力页

- `worktree-isolation` — worktree 隔离（Popen cwd 隔离）
- `worktree-spec-seeding` — worktree SPEC 播种
- `worktree-result-readback` — worktree 结果回读
- `worktree-hygiene` — worktree 卫生与复用
- `run-isolation` — run 工作树隔离与冲突恢复
- `merge-back` — merge-back 合并回主树
- `merge-back-precheck` — merge-back 预检
- `merge-circuit-breaker` — merge 熔断
- `merge-rehearsal` — 合并预演与语义冲突直通修复
- `merge-untracked-guard` — 未跟踪文件合并守卫
- `mergeback-inplace-repair` — merge-back 原位修复
- `mergeback-stashpop-self-heal` — stash pop 自愈
- `stashpop-conflict-treatment` — stash pop 冲突处置
- `push-ref-hygiene` — 推送引用生命周期卫生
