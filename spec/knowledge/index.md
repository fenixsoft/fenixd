# 知识真相源总目录

本项目知识按**能力域**组织：域内一能力一页，只装当前生效的业务规则；
历史演变见各页「溯源」段与 `spec/archive/`。能力页由存量回填批次逐步产出，
各域导航页先行登记能力条目（能力页落盘后升级为链接）。
