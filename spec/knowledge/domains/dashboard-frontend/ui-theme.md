# 界面主题（浅/深双档）

Dashboard 的浅/深双主题能力：三档偏好状态机、首帧防闪烁、嵌入宿主跟随与全站深色呈现。色值实现单源为 `core/dashboard/static/src/theme.ts`（浅/深双 token 族 + 按档取值助手）。

## 规则

- **三档偏好**：`system / light / dark`，持久化浏览器 localStorage 键 `fenix.theme`（值域即三档字符串）；缺省（无键/非法值）= `system`，跟随 `prefers-color-scheme` 并监听其变化实时切换（监听器随组件生命周期对称清理）。配置页「界面风格」页签三档单选即时生效，不参与 `PUT /api/config` 保存路径。顶栏右上角主题切换图标为第二入口：单击写入显式 `light`/`dark` 偏好（themePreference 状态机同一入口，文档根 `data-fenix-theme` 与 ConfigProvider 同步翻档，localStorage 键与首帧防闪烁、三档控件同源），图标语义=点击去向（浅档显月亮、深档显太阳；`system` 偏好按当前生效档取向），standalone 全页常驻（含豁免页），embed 档不渲染（ProLayout 顶栏 embed=1 时关闭），嵌入风格仍由宿主 dsh web 跟随；键盘 Enter/Space 可达。
- **首帧防闪烁**：`config/config.ts` `headScripts` 注入内联脚本（Umi 4 headScripts 先于样式表执行），读 localStorage 偏好 + `embed=1` theme 参数 + prefers-color-scheme → 首帧前写 `data-fenix-theme`；脚本逻辑与 `src/utils/themePreference.ts` 状态机同构并注释互指，两处 MUST 同批改（themePreference.test.mjs 提取内联脚本直载断言三输入组合）。
- **token 单源**：`theme.ts` 每个语义常量浅/深两档，全部界面颜色（antd 语义 token 或 DSH_* 常量）均取自该单源，无散落硬编码新色值。浅色档值冻结为零回退基线：改动 theme.ts MUST NOT 改变浅色渲染结果（浅档常量逐字节稳定）。深色档逐项翻译自 dsh web 深色调色板（`@deepseek-ai/dsh-client-ui-theme` 包深色档 `--dsw-*`，alias 语义对位），theme.ts 深色档即映射表的唯一落地事实。antd 侧深色档 `theme.darkAlgorithm` + 显式 token 覆写（darkAlgorithm 派生不信任）；**主色种子陷阱**双向成立：浅档黑主色与深档白主色下 `colorPrimaryBg` 派生族均不可作选中底（darkSeedBgToken 守卫），深档反墨档成族显式——主按钮字色与 Checkbox 勾选符号/Radio 圆点/实底选中字均取页面基底反相（DSH_BG_BASE_DARK，MUST NOT 用近白文字；antd 这些键硬编码 `colorWhite`，白主色种子下白底白勾不可见，深档 MUST 反写 `colorWhite`）。MUST NOT 挂 theme 级 borderRadius 覆写（2026-11-03 用户裁决）；无过渡动画（静态渲染红线）。
- **ProLayout 主色族 scope 按档切**：ProLayout（pro-components）内部按布局分区自建 ConfigProvider scope（以 settings.colorPrimary 重播种主色派生族），主色族消费面（页签选中态/墨条/复选框/进度条/单选控件）深档走双通道——runtime 布局配置深档覆写 `colorPrimary=DSH_PRIMARY_DARK`(#f9fafb) + `navTheme='realDark'`（浅档零增键、路径逐字节不变），布局 token 通道 top-level `colorPrimary`/`colorLink`(#7aaaff) 为双保险兜底；组件级显式 token（theme.ts components 的 Tabs/Progress/Radio/Checkbox 主色族键）把用户感知面与派生链解耦——显式键不依赖派生链，scope 重算也直达；实测不消费主色派生的组件（Segmented）不挂键。验收以 ProLayout 主内容/侧栏 scope 计算变量断言为准（`--ant-color-primary`/`--ant-color-link`），不信任文档与截图；antd darkAlgorithm 对种子主色族 CSS var 一律再渲染，派生值（#d7d8d8/#6b94dc 系）属 #f9fafb/#7aaaff 的合法深档形态，浅档残留形态（dark(#0f1115)=#101115、dark(#4176e6)=#3a67c7 系）判缺陷。「内层 scope + 白/黑种子」场景的选中/hover/active 底必须显式给值：根 ConfigProvider `components.Menu.itemSelectedBg` 不可穿透 ProLayout 内层 scope——scope 以 `token.colorPrimary` 重播种后派生族整体重算，`itemSelectedBg` 缺省派生 `colorPrimaryBg`，白主色种子（#f9fafb）经 darkAlgorithm 派生出浅灰高亮底族，深档侧栏选中药丸呈浅灰+白字不可读；侧栏 Menu 选中底由 `dshLayoutTokenDark.sider.colorBgMenuItemSelected`（白 6% 药丸）+ global.less 深档块 `!important` 压内联同构双保险（浅档 dshLayoutToken 不挂此键，浅档逐字节不变）。
- **切档热切换与首挂冻结物**：umi 插件 Layout 的运行时布局配置（app.tsx `layout()` 的 navTheme/colorPrimary/token）只在 route/initialState 变化时重跑，主题翻档不触发——内层 scope 停旧档而根 ConfigProvider 直接消费面已翻档=半明半暗混合态。切档经 rootContainer 按档 `Fragment key={scheme}` 重挂 children（含插件 Layout），运行时布局配置以新档整跑一遍，语义等价「免刷新的完整重载」；代价为切档瞬间页面级状态（滚动位/未提交表单）随重挂重置，浅档启动 key='light' 仅静态值行为不变。ProLayout `.ant-pro-layout-bg-list` 全视口装饰层（pointer-events:none）以 inline style 携带 bgLayout 渐变，只在 ProLayout 首次挂载（整页加载）按档求值，切档/路由变化均不重算——浅档白色渐变横带在深档恒残留并盖住内容区顶签行；深档由 global.less 深档块渐变 `!important` 压内联兜底（值与 theme.ts 单源镜像 #232324→#151517 28%），浅档不进该块保持白色渐变原貌。取证陷阱：该层 elementsFromPoint 不可见（pointer-events 穿透）且底色走 background-image 非 background-color，DOM 扫描易漏检；「body 涂红反证」为最快定位法（涂红后白带不变→其上有不透明层→枚举 pointer-events:none 层命中）。
- **CSS 变量双档**：`global.less` 界面色走 `--fenix-*` 主题变量（`:root` / `[data-fenix-theme='dark']` 双档，值源 theme.ts 档位镜像同步），不新增散落硬编码（配色单源红线）；页面组件的 JS 侧常量消费统一引 var() 形态（切档零 React 参与即时生效）；React 组件按档取值走 `utils/themeHooks` 的 `useThemeScheme`/`useDshPalette`（SSR 快照第三参必给，react-dom/server 渲染测试依赖）。成对常量的深档值双源镜像（theme.ts 深档常量 + global.less 深档定义）MUST 同批同步改：次级文本 tertiary 深档 #adb2b8（对齐 dsh 深档 label-tertiary；浅档 #64748b），消费点（SPEC 列表/详情/概览表格次级文本）走 CSS var 双档取值，改值只动双源定义 MUST NOT 逐点改内联色值；磁贴阴影 `--fenix-tile-shadow-*` 深档黑 alpha（浅档灰 alpha）。深档布局 chrome（顶栏玻璃/侧栏 soft 底）双通道：`dshLayoutTokenFor` 运行时按档 + global.less 深档 CSS 覆写层兜底（值同源镜像恒一致）。
- **嵌入跟随（iframe 侧契约）**：嵌入 dsh web（`embed=1`）时主题跟随宿主——初始经挂载 search 可选参数 `theme=dark|light` 注入（值域白名单，缺省/非法回退独立逻辑），运行期经 host→iframe postMessage `{kind:'fenix-dashboard:theme', theme}` 实时切换（`utils/themeChannel.ts` 三层校验：`event.source===window.parent` + kind 白名单 + 值域，不合法静默忽略）。宿主档生效时嵌入态不读写 localStorage（不污染独立偏好）；嵌入态配置页「界面风格」控件锁定显示「跟随 dsh web」。宿主侧监听与广播由 dsh-plugins 仓桥接插件实现，kind 字面量与本侧 `THEME_MESSAGE_KIND` 双仓镜像逐字节一致（双仓显式契约裁定见 ADR-378，禁同源直读宿主 DOM）。
- **全站深色呈现**：六页（overview/projects/settings/help/activities/command-center）+ 指挥中心 + 全局组件深档完整可用可读；嵌入毛玻璃标题带深档 rgb 通道 MUST 与深档 DSH_BG_SOFT 一致且透明度小于 1（layout-chrome-tinting 守卫）；antd filled Tag 对自定义 hex 恒算浅色底，深档下自绘同色 alpha 形态（StatusTag filled 分支按档分流）；`progressPhase` 进度底轨淡色为产品指定的浅色语义，有意不随主题派生（非遗漏）；概览统计卡自绘次级灰（眉题/信息图标/图例）双档——浅档维持原 `rgba(0,0,0,*)` 黑系 alpha 逐字节不变，深档经 `useDimColor` 取 theme.ts 单源深档次级文字（textSecondary 系），深档值只经 pal 取值不落新字面量（配色单源红线）。SpecTimeline 时间轴节点磁贴整卡双档 token 化——卡底/边框 theme.ts `TIMELINE_TILE_*` 双档（浅档纯白底+发丝边、深档 #232324 系卡底+白 alpha 描边，与卡内引文框同层协调，无白卡×黑底引文框反转）、阴影走 `--fenix-tile-shadow-*` 双档，MUST NOT 硬编码白底卡，urgent 分支 colorError/colorErrorBg 语义 token 不随档。任务清单勾选块深档主色反转（`--fenix-task-check-bg` 白底 + 勾选字随 `--fenix-on-primary` 墨档）；处置链横线 `--fenix-chain-*` 双档（浅 #f1f5f9 / 深 #545557，ChainPanel hair 消费）。
- **Agent 运行记录 pane 与 Modal 弹窗主题**：Agent 运行记录三个呈现面（时间轴内嵌展开 / RunRecordModal / AdminRunModal）壳与 pane 均跟随主题，MUST NOT 设亮锁 ConfigProvider——弹窗壳随根 ConfigProvider 双档（深档 darkAlgorithm 深壳），pane 深档由 global.less claude-msg 变量组按 `[data-fenix-theme='dark']` 双档覆盖（pane/portal 同组逐键同构，shadcn HSL 三元组：bg #151517、card #232324、popover #2c2c2e、fg #f9fafb、muted-fg #adb2b8、primary #7aaaff）。antd v6 陷阱：Modal 的 portal 内容取不到嵌套 ConfigProvider 的主题作用域（壳 token 仍取根档，对普通子树立即生效的 Provider 对 Modal 壳无效）；v6 语义键已把 `content` 改名 `container`（`.ant-modal-content` 选择器不存在）。若某弹窗确需固定亮锁（亮面家族），壳必须用 `styles` 语义键显式定值（`container/header/title/close` 四键）。
- **claude-msg 深档文字与原生控件防御**：portal 弹层不在 `.claude-msg-pane` 后代位置、变量作用域不可达——pane 内容根 MUST 挂 `.claude-msg-portal` 类显式注入变量（浅/深两组与 pane 同批同步改）。tailwind typography 在 `.prose/.prose-gray` 元素上直写浅档 statics、祖先变量继承不生效——深档以 `[data-fenix-theme='dark'] … :is(.prose,.prose-gray)`（特异性 0,3,0）在 `.prose` 本体重定义 `--tw-prose-*`（值取 dsh 深档文字族）。tailwind.gen.css 无 preflight，pane 内原生 `<button>` 落 UA ButtonFace，color-scheme 随深档翻转呈中灰底——`:where(.claude-msg-pane, .claude-msg-portal) button { background-color: transparent }` 零特异性压 UA 默认（不与工具类竞级）。

## 代码锚点

- 主实现（浅/深双 token 族 + antd ThemeConfig 单源）：core/dashboard/static/src/theme.ts
- runtime 布局配置（ProLayout 主色族深档覆写 + dshLayoutTokenFor 布局 token 消费）：core/dashboard/static/src/app.tsx
- 主题状态机（三档解析/localStorage/matchMedia 监听）：core/dashboard/static/src/utils/themePreference.ts
- 首帧防闪烁内联脚本注入（headScripts，与状态机注释互指）：core/dashboard/static/config/config.ts
- 嵌入主题消息通道（THEME_MESSAGE_KIND 与三层校验）：core/dashboard/static/src/utils/themeChannel.ts
- CSS 变量双档定义：core/dashboard/static/src/global.less
- 按档取值消费方（useThemeScheme 与 useDshPalette 助手）：core/dashboard/static/src/utils/themeHooks.ts
- 配置页「界面风格」控件与嵌入锁定：core/dashboard/static/src/pages/settings/components/ThemePanel.tsx
- 顶栏主题切换图标（FiltersSlot 常驻 ThemeToggleButton）：core/dashboard/static/src/components/PageTitleBar.tsx
- 概览统计卡次级灰双档（useDimColor）：core/dashboard/static/src/pages/overview/components/IntroduceRow.tsx
- 挂载 theme 参数解析：core/dashboard/static/src/utils/embedMount.ts
- 守卫测试：core/dashboard/static/tests/themePreference.test.mjs、core/dashboard/static/tests/themeChannel.test.mjs、core/dashboard/static/tests/embedMount.test.mjs
