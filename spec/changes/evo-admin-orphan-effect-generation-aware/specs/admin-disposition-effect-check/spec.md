# Capability: admin-disposition-effect-check

## Adjudications

### 孤儿处置生效核查须代际感知

处置组终态后的生效核查，MUST NOT 仅凭 spec 当前状态快照判定处置未生效；MUST 先核查处置组完成时刻之后是否存在指向该 spec 的合法 gate transition 推进轨迹（解冻/复位/再冻结等代际前移），命中则判「已生效、被新代际取代」。

- 该情形下旧处置组 MUST 转记为已消解并回链新代际信号，MUST NOT 升级人工。
- 新代际信号 MUST 开立且携带旧处置组引用与轨迹证据行，保持升级链可追溯。
- 推进轨迹缺失或日志窗口不可用时 MUST 维持现行 fail-closed 升级语义（行为零变化）。

### 生效核查证据源

STATE 当前状态快照 MUST NOT 作为生效核查的唯一证据源；处置组完成时间戳与 gate transition 日志家族（含轮转备份）为代际判别的第一证据源。

## Scenario

- 处置生效后 spec 被新一轮验证再冻结：核查判「已生效、被新代际取代」，旧组消解回链，不产生人工告警，不触发重复仲裁调查。
- 处置确实未生效（处置完成后无任何推进轨迹）：维持升级人工，行为与现状一致。
- 日志轮转丢失、轨迹不可考：维持升级人工（fail-closed）。
