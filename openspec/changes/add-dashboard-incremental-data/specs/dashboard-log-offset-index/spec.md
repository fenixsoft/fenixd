## ADDED Requirements

### Requirement: 日志块偏移索引

为 `.fenix/logs/fenixd*.log` 维护 `.fenix/logs/.idx/` 块偏移索引：记录 `{size, blocks:[每 64KB 块首行偏移]}`。
`get_spec_timeline` 与 `get_recent_events` 改由索引定位读取段：只读目标窗口对应块段（最大 1MB），不再全量读文件。

#### Scenario: 查询只读窗口
- **WHEN** 日志文件 7.5MB，查询最近 10 分钟事件
- **THEN** 只读取文件尾部 ≤1MB 窗口（以 read 字节数断言：filesize 而非全量）；结果与全量扫描口径一致（事件内容与顺序相等）

#### Scenario: 索引热更新
- **WHEN** 日志追加新行后再次查询
- **THEN** 索引被追加更新到新 size（无需重建），新行可被查到；追加场景下索引重建次数为 0

#### Scenario: 索引损坏容错
- **WHEN** 索引文件缺失或 size 与日志不符（如日志被截断轮转）
- **THEN** 查询不报错：重建索引（≤1 次全量扫描）后返回正确结果，后续沿用新索引

### Requirement: 时间轴窗口截断语义

时间轴与事件查询按最近窗口截断：查询点早于索引覆盖窗口（尾部 1MB 内 16 块 + 1 个身位）的部分
不追溯，返回窗口内最近内容；前端时间轴按「最近 N 条」展示，不要求完整历史。

#### Scenario: 超窗截断
- **WHEN** 查询窗口起点早于索引记录的范围内起点
- **THEN** 返回从窗口起点开始可得的记录（可少于全量），不抛错不阻塞
