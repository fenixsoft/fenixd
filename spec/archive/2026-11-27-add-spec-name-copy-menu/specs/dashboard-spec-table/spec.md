# dashboard-spec-table 变更增量

## MODIFIED Requirements

### Requirement: 名称列右键复制菜单

系统 SHALL 在 SPEC 列表页桌面表格的名称列（SPEC 标题区域：英文名主行及其下方中文标题副标题行所在的单元格）支持右键交互：用户在名称列上点击鼠标右键时，系统 SHALL 拦截浏览器原生菜单，在鼠标位置弹出上下文菜单，菜单含单项「复制 SPEC 名称」；fix-\* 树形子行与已归档视图行的名称列同样支持（复制为只读操作，不区分视图收敛）。名称列以外的区域（其他列单元格、表头、空白处）右键 SHALL 保持浏览器原生默认行为，不弹自绘菜单。菜单 SHALL 在点击菜单外任意位置、滚动列表或按 Esc 键时立即关闭；菜单靠近视口底部/右侧边缘时 SHALL 整体翻转（向上/向左），始终完全在视口内。菜单与其弹层 SHALL 经 portal 渲染于表格行命中面之外。

#### Scenario: 右键 SPEC 标题弹出复制菜单

- **WHEN** 用户在 SPEC 列表某行的名称列（含英文名或中文标题区域）上点击鼠标右键
- **THEN** 浏览器原生菜单不出现，上下文菜单在鼠标位置可见，含「复制 SPEC 名称」菜单项

#### Scenario: 非名称列区域右键保持原生默认

- **WHEN** 用户在状态列、优先级列、表头或页面空白处点击右键
- **THEN** 出现浏览器原生默认菜单，不弹自绘菜单

#### Scenario: 菜单关闭与边缘不溢出

- **GIVEN** 右键菜单已打开
- **WHEN** 用户点击菜单外任意位置、滚动列表或按 Esc 键
- **THEN** 菜单立即消失；在视口底部/右侧边缘附近的名称列右键时菜单整体仍在视口内（向上/向左翻转）

#### Scenario: 树形子行与归档行同样可用

- **WHEN** 用户在 fix-\* 树形子行或「已归档」视图行的名称列上右键
- **THEN** 同样弹出「复制 SPEC 名称」菜单，复制的是该行自身 SPEC 的英文名

### Requirement: 复制英文名到剪贴板

用户点击「复制 SPEC 名称」菜单项时，系统 SHALL 将该 SPEC 的英文名（`record.name`，kebab-case id；不含中文标题、不含项目名前缀）写入用户剪贴板，SHALL 以非阻塞提示告知复制成功，且菜单 SHALL 随即关闭。剪贴板写入 SHALL 复用既有 `copyToClipboard` 单源助手（`navigator.clipboard.writeText` 首选 + 隐藏 textarea `execCommand('copy')` 降级），MUST NOT 在本 SPEC 内另写剪贴板实现——保证公网纯 HTTP（非 secure context，`navigator.clipboard` 缺失的 frp 隧道访问）下复制照常可用。写入失败时系统 SHALL 给出失败提示，MUST NOT 误报成功。

#### Scenario: 点击复制项英文名入剪贴板

- **WHEN** 用户在某 SPEC 名称列右键弹出菜单后点击「复制 SPEC 名称」
- **THEN** 该 SPEC 英文名被写入剪贴板，出现非阻塞成功提示，菜单关闭；粘贴所得文本与该 SPEC 英文名逐字一致（不含中文标题与项目名）

#### Scenario: 非安全上下文下降级可用

- **GIVEN** 经公网纯 HTTP 域名访问 dashboard（非 secure context，`navigator.clipboard` 缺失）
- **WHEN** 用户点击「复制 SPEC 名称」
- **THEN** 复制经 execCommand 降级路径同样成功，成功提示不变

#### Scenario: 复制失败如实提示

- **WHEN** 剪贴板写入抛出异常或降级路径返回失败
- **THEN** 出现失败提示（含错误原因），不出现成功提示

### Requirement: 右键复制零回归

右键菜单及其复制操作 MUST NOT 触发行级导航：右键本身不进入 SPEC 详情页，点击菜单项后停留在列表页。名称列既有交互 SHALL 零回归——整行点击进详情、名称 Why 悬浮提示、名称列排序、中文副标题渲染、fix-\* 树形展开/收起、前端过滤与表头排序均不受影响；2 秒自动刷新/SSE 重绘后右键菜单接线 SHALL 保持正确（新数据行同样可右键复制）。

#### Scenario: 右键与复制不触发导航

- **WHEN** 用户在名称列右键弹出菜单并点击「复制 SPEC 名称」（或按 Esc 关闭菜单）
- **THEN** 页面停留在 SPEC 列表页，不进入该 SPEC 详情页；此后点击该行其他区域仍正常进入详情

#### Scenario: 既有名称列交互零回归

- **WHEN** 在接入右键菜单后执行列表常规操作（整行点击进详情、悬浮名称看 Why 提示、表头排序、类型/状态/关键字过滤、fix-\* 树展开收起、等待 2 秒自动刷新）
- **THEN** 各交互行为与接入前一致；刷新产出的新行名称列右键同样弹出复制菜单
