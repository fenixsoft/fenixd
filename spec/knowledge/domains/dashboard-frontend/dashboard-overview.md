# 项目总览页

Dashboard 首页的跨项目概览：统计卡 + 项目卡片墙，2 秒自动刷新，故障隔离可降级。

## 现行规则

- 页面顶部为统计卡：SPEC 总数、任务进度、活跃 Agent、Token 消耗四卡，卡片等高、数值与说明两端对齐；下方为被监控项目的项目清单（标题、过滤、更多链接）。
- 每张项目卡片展示：项目名、SPEC 总数、各状态计数、任务总进度（已完成/总数 + 百分比进度条）、问题/阻塞数、活跃 Agent 运行数，以及 daemon 健康徽标——`daemon="running"` 显示「运行中」（正向色），`daemon="stopped"` 显示「未运行」（弱化/警示色）；自动发现的项目继续带「自动」标记。
- 所有被监控项目在同一概览页统一展示，任意项目可点击下钻到其 SPEC 列表；概览每 2 秒自动刷新（轮询 `/api/overview`）。
- 多项目状态自动跟随：新启动 daemon 的项目（被发现或已注册）在服务端发现缓存（默认约 10s）与健康缓存（默认约 5s）过期后自动出现/更新，无需重启 Dashboard 服务或手动刷新。
- 项目级错误态：卡片摘要 `error` 字段非空时，卡片呈错误态（警示色）并展示错误原因文案，不得以正常 daemon 徽标/进度数字形态呈现而误导；错误态卡片仍出现在概览中（不被静默过滤——它本身就是「该项目当前不可用」的可见信号）；单项目错误态不影响其它项目卡片的渲染、`totals` 的展示或页面整体可用性。
- 加载失败降级：`/api/overview` 请求失败且此前无成功数据时，显示错误提示与「重试」入口（触发重新请求），不得渲染空白页、空白骨架或永久加载态；已成功加载过之后刷新失败（30s 心跳或 SSE 触发的重载），继续展示上一次成功的数据并在其上显示错误提示，不得清空已展示的项目卡片与 `totals`；下一次刷新成功后展示最新数据、错误提示消失。
