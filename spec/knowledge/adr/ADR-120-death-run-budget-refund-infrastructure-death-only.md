# ADR-120：死亡 run 预算豁免仅限基础设施性死亡

date: 2026-09-19
status: accepted

## Context

死亡 run 预算豁免（ADR-047：豁免在死亡判定点回退）的立论是「网关死亡没跑满预算就死，不该计费」。但监督超时/被判停滞而杀的 run **跑满并超支**了整份预算：这类 run 被杀后无结果文件、终态为 None，同样命中豁免 → 预算刹车失效 → 重派不耗预算、无上限，一次存量挂起被放大成无限重试。跨 attempt 又无结构化诊断继承，每个 attempt 重复考古同一个已定性问题。

## Decision

- 预算豁免按终态细分：仅适用于**基础设施性死亡**（daemon 关闭/重启连带的 interrupted、归因指向网关链路耗尽）；监督超时与停滞击杀（终态 error 且归因为超时/停滞）**不豁免**——它确实消耗了整份预算。两类成本语义相反，用同一豁免退掉后者等于拆掉唯一的刹车。
- 跨 attempt 继承结构化诊断（终态类型、归因、已定性结论、已提交进度：分支与已勾任务），随 error 注入下轮上下文；error 文本的清理不得连带清诊断字段。

## Consequences

- 预算刹车对「真烧钱」的 run 恢复有效，豁免继续保护「没跑就死」的 run；网关链路耗尽的归因白名单须与既有预算语义同源，避免细分误伤真实网关死亡。
