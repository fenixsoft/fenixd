# ADR-335：config provider 引用校验单源，行为分叉收在处置层

date: 2026-11-08
status: accepted

## Context

provider 引用校验曾在两条配置路径各自为政：Dashboard 设置保存路径对未注册引用拒绝保存，daemon 加载/热加载路径却只记 ERROR 静默跳过（不阻塞加载）。项目配置 provider 名一字之差（`bigmodel.cn` vs 注册表 `bigmodel-cn`）时，48 条 ERROR 被静默吞掉、整条模型链失效、agent 持续派发失败——用户能看到的只有 spawn 失败，错误信号与真实原因（配置名字写错）之间无可循迹的桥。

## Decision

引用校验规则（角色遍历、字符串/对象数组两形态、坏名收集、相似名建议）抽为单一实现，daemon 加载路径与 Dashboard 保存路径共用，禁止两路径规则漂移。两路径的行为差异只收在处置层：保存路径 ValueError 当场拒绝（用户当场看到）；加载路径不发阻塞——daemon 不因配置坏拒绝启动的可用性纪律保留，改为发带相似名建议的可操作配置告警，「跳过」必须可观测。

## Consequences

后续任何新增的配置读写路径都不得自建引用校验第二实现；校验算法演进（建议阈值、归一规则）只动一处。加载侧告警链路 fail-open（配置损坏不阻断 daemon 启动），但坏配置必然留下带修复建议的告警痕迹。
