# ADR-070：配置校验按缺陷性质分类——键集漂移逐键降级，值非法整段拒绝

date: 2026-09-11
status: accepted

## Context

配置为 plain dict + 手写白名单。键集校验若整段拒绝：代码新增合法键后，旧进程热重载每 30s 重试失败并重复报错，启动则直接 FATAL 起不来；而值/类型非法是配置真坏，必须拦截。既有先例（timeout_overrides 白名单校验：未知键逐键 ERROR + 忽略 + 其余生效）证明逐键处理可行。

## Decision

- **键集不匹配（代码演进产物）→ 逐键降级**：跳过该键校验但**保留键**在有效配置中——运行时解析本就无白名单，旧代码不派发该角色则键惰性，新代码（重启后）立即生效，无任何崩溃路径。逐键非阻塞 ERROR，文案内嵌 `touch .fenix/restart_request` 重启处方；同一键每进程生命周期只报一次（防热重载重试风暴刷屏）。
- **值/类型非法（配置真坏）→ 整段拒绝**：已知键的形态错误仍 raise，不做部分生效；启动期值类错误仍 FATAL。无法逐键时按段忽略 + ERROR（对齐 optional yaml 哲学）。
- 不引入「从配置剔除未知键」机制：嵌套剔除复杂，且旧进程剔除后新进程反而丢配置。

## Consequences

- 键集漂移不再造成热重载失败风暴与启动失败；typo 键被点名，且 Dashboard 写入校验从入口拦截主要 typo 面。
- 宽容面仅限键集：坏值仍 fail-fast，配置 typo 长期潜伏的残余风险由降级告警与入口校验兜住。
