# ADR-253：run 预算观测面与判定面分离，活性矩阵收窄只许缺省关闭守卫形态

date: 2026-10-08
status: accepted

## Context

ADR-103 确立轮次上限活性续期矩阵「任一活性即 extend、不腰斩健康推进 run」之后，出现两类扩展诉求：给判定点补充剩余工作量、簿记占比等新证据维度，以及在大 spec 末位续期不济时提前止损。实证（potplayer-base cimbar 38 任务 spec）表明簿记占比异常（熔断 run 15.5% vs 正常 run 5.7%）只是低效信号——大 spec 首轮建任务簿记天然偏高，单独作为 kill 依据必误伤；而对「有活性即续」的任何收窄若缺省开启，评审/裁决车道 run 内勾选进度恒零，开启项目内必被误杀。

## Decision

轮次/run 预算轴的新证据维度一律只做观测面（evidence 注记、事件与 run_metrics 字段、WARNING 留痕），不参与判定语义——观测面恒开、不受灰度开关门控、取数故障记 unavailable 不误判，任何单一观测信号不得单独改变 extend/kill 结论。收窄 ADR-103 活性矩阵的机制（提前判停类守卫）只许以一种形态引入：缺省关闭灰度、多条件保守合取（末次扩容判定点 + 剩余工作量超阈 + run 内进度近零）、仅限实现车道、收口复用既有 kill+WIP 保全锚点；扩容封顶等既有终态语义优先于守卫，关闭时判定与引入前逐位一致。预算抬升类推算只抬不压（生效序 override > 推算 > base），规模解析单点（禁止第二套 tasks.md/交付物解析）。后续「更聪明的判停」类 SPEC 必须以 supersede 本裁定的方式突破该形态，不得默认绕开。

## Consequences

低效/打转类 run 不被自动止损，其成本只沉淀为观测字段供人工与自省消费（消费面须另立项）；提前止损收益只在显式开启灰度的项目兑现，开启项目首次触发需复核告警证据。活性矩阵主干语义与既有事件/读侧契约零破坏，新字段附加不替换；推算抬升的最坏墙钟增幅由既有无活性 kill 兜底（无活性 run 一次扩容都拿不到）。
