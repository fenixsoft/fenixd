# ADR-121：blocked 二分类以杠杆归属为判据，冻结与告警成对单入口

date: 2026-09-19
status: accepted

## Context

blocked 是唯一「等人工」态，承载两种语义：冻结转人工（需人在场，admin agent 无杠杆）与阻塞待 admin（admin 可自动修复：改环境、起草契约、清 git 状态）。十余个写入点各自手工记得（或忘了）打 frozen 标记、发告警，无机械化约束——已实证「有 frozen 无告警」的静默冻结，以及整类路径（评审否决/耗尽）漏标。

## Decision

- 分类判据为单一问题：「admin agent 对这类停摆有可操作杠杆吗？」无（改方案、撤案、判是否值得再跑）→ **冻结转人工**：frozen=True + 人工升级告警；有 → **阻塞待 admin**：不写 frozen，admin 巡检介入。判据只看杠杆归属，不依赖文案。
- 冻结必须经单一成对入口：一次调用完成 status=blocked + frozen + 规范 error 前缀 + 人工升级告警，从结构上消除「冻结不告警」；既有站点收敛到该入口，恢复路径内的冻结逐 spec 触发告警、不聚合丢失。

## Consequences

- 新增 blocked 写入点默认继承正确分类与告警；告警发送者的依赖边界以回调/参数注入解耦，不改变「成对、单一入口」不变式。
- 误归冻结的代价是 admin 不再介入，以保守归类控制——只把 admin 从无实际修复动作的类别归入冻结，其余维持阻塞。
