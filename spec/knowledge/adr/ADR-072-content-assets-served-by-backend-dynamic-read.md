# ADR-072：内容型资产由后端端点动态读盘伺服，不打包进前端 dist

date: 2026-09-10
status: accepted

## Context

前端 dist 为入库构建产物，任何进 bundle 的内容改动都要重建 dist 并提交产物。文档类内容需要轻量频繁演进，与「改一个字重 build 一次」的发布链天然冲突。

## Decision

- **内容型资产（帮助文档等）由后端端点实时读盘伺服**，不打包进前端构建产物：server 从框架仓库 docs 目录实时读盘（框架单副本软链部署，由代码位置向上解析框架根定位可靠），前端按需拉取。编辑 .md 刷新即生效、零 dist 重建。
- **文档名白名单 + 解析后 real path 落点校验**沿用文件端点既有安全模型；目录缺失返回空清单、单篇缺失返回 404，由前端空态兜底，不做在线编辑与鉴权。
- **重依赖渲染库动态 import 按需加载**，不进首屏与主 bundle；渲染异常回退原始文本不白屏。
- 该边界确立「内容 vs 代码」分野：内容走动态读盘，代码改动仍须重建 dist。

## Consequences

- 文档与代码独立演进；文档与代码的事实漂移靠评审纪律约束。
- 后端承担内容端点的路径安全职责，新增内容类型沿用同一模型接入。
