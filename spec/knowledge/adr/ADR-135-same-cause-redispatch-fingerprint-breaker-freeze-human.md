# ADR-135：同因重派熔断按归因指纹计数，达阈值冻结转人工

date: 2026-09-22
status: accepted

## Context

通用失败重派分支在重试计数达上限时把计数清零后照常重派，重试上限形同虚设：每轮都真实成功、仅 spec 层判失败的 run 被同因连续重派，每轮整支已提交成果被丢弃。既有 max_retries 的语义是「连续失败重试次数」，直接在其上加熔断会改变 transient/一般失败的既有行为面。

## Decision

- 熔断维度是「同因」而非「次数」：对失败归因文案做归一化指纹（剔除 run_id/时间戳/路径等易变段，保留原因主干），连续同指纹计数；归因差异化即重置——每轮都在变的原因不该熔断，每轮不变的原因才该。
- 达阈值（可配，缺省保守取 3）即冻结转人工，MUST NOT 再入队：走单一冻结入口（blocked + frozen 标记 + 人工升级告警）；冻结文案 MUST 内嵌「原状态」子串与指纹/轮数，使官方解冻通道能把 spec 还原为可调度状态而非落兜底猜测；解冻与同族计数字段同款原子清零。
- 计数载体为 STATE 内部字段并 MUST 随 daemon 重启保持（进序列化键表并有持久化测试）。
- 作用域边界：该 streak 只由通用失败重派分支喂入；既有各熔断/退避通道（merge 指纹、provider transient 排程、锁冲突退避、守卫 retry 封顶）独立记账、互不喂入、不被重复计数。

## Consequences

- 同因空转重派获得硬上界，预算损失从无界收敛为阈值轮；真需多轮修复的 spec 因指纹变化不被误冻。
- 指纹归一化粒度是主要漂移风险，MUST 配「不同因不误熔断」回归用例校准（只剔除易变段）。
