# ADR-165：外部工具参数按性质分流注入通道，单通道优先防遮蔽

date: 2026-09-24
status: accepted

## Context

外部工具（审查引擎等）的可调参数有三种性质：持久化配置键、纯 CLI flag、兼具两者。run 级配置直写是确定性通道但仅覆盖持久化键；提示词命令示例可覆盖 flag 但属软约束（实现者不照抄即失效）。同一参数若配置与提示词双通道并存，实参优先的遮蔽会让排障无法判定生效值来源。

## Decision

- 新增外部工具可调参数 MUST 先实测判定其性质，按性质分流：持久化配置键 → run 级配置直写（确定性生效）；仅 CLI flag → 提示词命令示例承载（完整串+用例断言）。
- 同一参数禁双通道并存（单通道优先）：即使参数兼具持久化键，若同族参数只能走提示词，则一并走提示词保持同型，避免「实参与配置旧值」遮蔽歧义；软约束若实测频繁失效，升级路径是整体切换到配置通道而非叠加第二通道。
- 参数非法/缺失/环境缺口一律回退缺省，MUST NOT 使审查失败或阻塞派发——配置类缺口禁被当交付物缺口重派。
- 缺省值取向「更省更快」侧由用户显式选定；未经理 A/B 实测的归因（如并发是超时根因）只作推断记录，机制设计不依赖推断成立（单独修另一参数也能缓解）。

## Consequences

外部工具参数接线有机械判定顺序（实测性质→通道分流→单通道）；生效值来源单一可排障；配置缺口不烧重派预算。
