# ADR-315：升级边处置链默认化，人工裁决为例外出口

date: 2026-11-03
status: accepted

## Context

升级信号长期直达人工队列：人工裁决是升级的默认终点。三个结构性代价被实证——触发面靠白名单枚举，新信号类型（如 inconclusive_loop/warning_stale_triage）天然覆盖不到而直接砸人工；已解决事故的告警因缺关联键永久滞留人工队列；Admin/Arbiter 两条自动化车道各自为战，没有统一的处置次序，人工在自动化可用时仍被即时打扰。

## Decision

全部升级边信号（`freeze_for_human` 全族与 `_send_human_escalation_alert` 全部调用点）默认进入两级自动化处置链，链序固定 Admin→Arbiter→人工；人工裁决降为例外出口——仅链终点（Arbiter 失败/复现配额耗尽）产生人工告警。配套裁定：

- 触发面黑名单制：默认入链、黑名单配置排除（初始空集 kill switch），不做白名单枚举；
- 链入口按信号来源判定防自环：链成员的处置输出只走链内转单边，禁止作为新信号重新入链；
- 降噪分级是「人工队列」的属性而非「信号」的属性：链入口不按 severity 过滤，降噪只在降级态（黑名单/关闭/链失能 fail-open）的人工队列面生效；
- 降级态行为与无链时代逐字节一致（fail-open），配置修复自动恢复入链。

后续新增升级边信号默认入链；要求人工直达或引入信号级新降噪面的，须显式 supersede 本裁定。

## Consequences

人工感知延迟从「即时告警」变为「链跑完才上升」，最坏延迟由单飞队列与配额上限封顶，过程可见性由处置链视图与时间轴全链节点补偿。链内成功零 admin_alerts 落盘，告警条目不再是链上在办件的可见性载体。降噪不再保护链入口，低严重度循环信号同样消耗链配额。
