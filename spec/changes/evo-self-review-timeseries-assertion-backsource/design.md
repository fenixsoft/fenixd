# design.md

## 设计决策

1. **落点选模板而非核查链**：evo 核查环节已多次成功拦截失实（无一条错误 SPEC 落地），缺陷在「写」不在「审」；在 agents/self-review.md 的写作纪律区与 :24 证据边界归因条款同构追加一条，成本低、触发点前置。
2. **条款措辞可执行**：要求「同句附每晚原始数字与口径」使失实在落笔瞬间自暴露（凑不出每晚数字即写不出断言），比抽象的「要准确」可核查。
3. **契约测试防回退**：模板是纯文本、无类型保护，以关键词契约测试同时守护新旧两条纪律的存在，防后续模板改写静默丢条款。

## 与存量工作的边界

- evo-self-review-evidence-bound-attribution：管「根因归因的证据边界」（形态层结论须有证据支撑）；本 spec 管「时序数值断言的回源」，触发条件不同（归因层级 vs 数值口径），互补不重叠。
