# 规划与出题

规划与出题。本域能力条目清单如下（能力页由存量回填批次逐步产出，落盘后此处升级为链接）。

## 能力页

- `native-spec-generation` — 基于 openspec 的原生抽题生成
- `planner-route-map` — planner 路由地图注入
- `planner-generation-throttle` — 出题生成节流治理
- `planner-contract-findings` — 规划期验证契约发现
- `planready-artifact-gate` — planready 阶段产物硬门
- `degrade-annotation` — 降级路径的结构化注解
