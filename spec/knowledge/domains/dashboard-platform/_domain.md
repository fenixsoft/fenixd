# 仪表盘服务

仪表盘服务。本域能力条目清单如下（能力页由存量回填批次逐步产出，落盘后此处升级为链接）。

## 能力页

- `dashboard-server` — dashboard 服务端
- `fenix-dashboard-skill` — dashboard 技能入口
- `dashboard-instance-lifecycle` — dashboard 实例生命周期（看门狗）
- `dashboard-sse-refresh` — SSE 增量刷新
- `v2-sse-bridge` — v2 SSE 桥
- `dashboard-incremental-watcher` — 增量数据 watcher
- `dashboard-log-offset-index` — 日志偏移索引
- `dashboard-spec-summary-index` — SPEC 摘要索引
- `dashboard-data-modules` — 数据读取模块化
- `dashboard-read-path-performance` — 读路径性能优化
- `dashboard-connection-limit` — 连接数上限
- `dashboard-live-session` — 实时会话视图
- `v2-data-adapters` — v2 数据适配层
- `v2-sdk-vendor` — v2 vendored SDK
- `v2-shell-router` — v2 shell 与 hash 路由
- `v2-legacy-coexist` — v2 与旧版并存机制
