# unified-page-title-bar Spec

## ADDED Requirements

### Requirement: 副标题下方堆叠形态

PageTitleBar SHALL 支持副标题下方堆叠声明形态：声明页的副标题渲染在标题行**下方独立一行**（标题行 = 返回箭头 + 标题富节点；副标题行 = 12px tertiary 既有样式，左对齐与标题首字对齐），两行同处 sticky 标题栏内、栏高随内容自然增加。未声明堆叠的既有 subtitle 消费面 MUST 保持行内右侧形态不变（形态由页面声明切换，组件不全局翻转）。移动端维持既有「副标题不渲染」规则（零改动）。

消费面：v1 SPEC 详情（中文标题）与 v2 SPEC 详情（中文标题 · branch 组合）两页 SHALL 切换为堆叠声明；branch 副标题随之下移，两页形态一致。堆叠使栏高增加后，命中标题栏高度依赖的页内偏移常数（56/60、126/130 同族字面量）SHALL 按实际渲染盘点回校，既有守卫测试同步钉死新值。

#### Scenario: 声明页副标题堆叠在下方

- **WHEN** 打开 v1 或 v2 SPEC 详情页（副标题非空、非移动端）
- **THEN** 中文标题副标题渲染在标题行下方独立一行，左对齐标题首字，不再出现在标题行右侧

#### Scenario: 未声明页形态不变

- **WHEN** 打开任何未声明堆叠的既有 subtitle 消费面（若存在）
- **THEN** 副标题仍为标题行内右侧形态，与改动前一致

#### Scenario: 移动端零变化

- **WHEN** 窄屏视口打开声明页
- **THEN** 副标题不渲染（既有规则），栏高与改动前一致

#### Scenario: 偏移常数回校

- **WHEN** 声明页栏高因堆叠增加
- **THEN** 该页（及页内 sticky 元素）的标题栏高度依赖偏移常数已按新栏高回校，页签/内容区无遮挡错位，pageTitleBar / pageChrome 守卫测试全过
