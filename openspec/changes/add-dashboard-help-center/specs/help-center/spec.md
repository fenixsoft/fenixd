# help-center 规格

## ADDED Requirements

### Requirement: 侧边栏「帮助」菜单项
Dashboard 侧边栏 SHALL 在「运维」菜单项之下新增「帮助」菜单项（带图标，路径 `/help`），点击后进入帮助中心页面；顶栏面包屑 SHALL 对 `/help` 路径显示「帮助」。

#### Scenario: 菜单位置与跳转
- **WHEN** 用户打开 Dashboard 并查看侧边栏菜单
- **THEN** 「帮助」出现在「运维」之下（菜单顺序：概览、项目、设置、运维、帮助），点击后页面切换为帮助中心且 URL 变为 `#/help`

#### Scenario: 面包屑正确
- **WHEN** 用户处于帮助中心页面
- **THEN** 顶栏面包屑显示「帮助」

### Requirement: 帮助文档读取 API
Dashboard 后端 SHALL 新增只读端点：列出 `docs/help/` 下的文档清单（文件名与标题），以及按名称返回单篇文档的 Markdown 正文。文档 SHALL 从框架仓库的 `docs/help/` 目录动态读取（每请求实时读盘），使文档更新无需重建前端 dist。端点 SHALL 做路径白名单校验：仅允许读取 `docs/help/` 内已存在的 `.md` 文件，拒绝目录穿越与非白名单路径。

#### Scenario: 获取文档列表
- **WHEN** 前端请求文档清单端点
- **THEN** 返回 `docs/help/` 全部 .md 文件的列表（含文件名与解析出的一级标题），顺序与文档编号一致

#### Scenario: 获取单篇正文
- **WHEN** 前端以合法文档名请求正文端点
- **THEN** 返回该文档的 Markdown 原文

#### Scenario: 拒绝非法路径
- **WHEN** 请求携带 `..` 穿越片段、非 .md 后缀或不存在的文档名
- **THEN** 返回错误（404/400），不泄露服务器文件系统信息

#### Scenario: 文档更新免重建
- **WHEN** 直接编辑框架仓库 `docs/help/` 下任一文档并刷新帮助页
- **THEN** 新内容即时生效，无需执行前端构建

### Requirement: 帮助页布局与渲染
帮助中心页面 SHALL 采用「左侧文档目录 + 右侧正文」布局：目录列出全部文档（按编号排序，当前选中项高亮），正文区渲染所选文档的 Markdown（标题/列表/表格/代码块/链接）。正文中的 mermaid 代码块 SHALL 渲染为图形（采用动态 import 按需加载 mermaid，不放大首屏体积），普通代码块保持等宽字体展示；文档内的相对链接 SHALL 可在帮助页内导航（切换到目标文档而非整页跳出）。

#### Scenario: 目录与正文联动
- **WHEN** 用户在左侧目录点击「SPEC 生命周期与状态机」
- **THEN** 右侧加载并渲染该文档，选中项高亮，URL 同步记录当前文档（如 `#/help?doc=03-lifecycle`），刷新后仍停留在该文档

#### Scenario: mermaid 图渲染
- **WHEN** 打开包含 ```mermaid``` 代码块的文档（如生命周期篇的状态图）
- **THEN** 该代码块渲染为可读的 SVG 图形而非原始文本；渲染失败时回退显示原始代码文本且不白屏

#### Scenario: 页内相对链接导航
- **WHEN** 用户点击正文中指向其它帮助文档的相对链接
- **THEN** 帮助页切换渲染目标文档，不离开帮助中心

#### Scenario: 默认进入目录索引
- **WHEN** 用户通过菜单进入帮助中心且未指定具体文档
- **THEN** 默认渲染 `README.md` 目录索引文档

### Requirement: 容错与空态
当框架仓库 `docs/help/` 目录缺失或为空时，帮助页 SHALL 显示友好的空态提示（不报错白屏）；单篇文档读取失败时 SHALL 在正文区显示错误提示并保留目录可用。

#### Scenario: 目录缺失空态
- **WHEN** `docs/help/` 目录不存在或无任何 .md 文件时打开帮助页
- **THEN** 页面显示「暂无帮助文档」类空态，无未捕获异常

### Requirement: 移动端适配
帮助中心页面 SHALL 适配窄屏（<768px）：目录与正文改为上下堆叠或抽屉式切换，正文可读性不劣化，复用项目现有移动端适配模式（useIsMobile + screen-xs 作用域）。

#### Scenario: 窄屏布局
- **WHEN** 视口宽度 <768px 时打开帮助中心
- **THEN** 目录与正文不并排显示，切换文档无需横向滚动，正文文字不溢出
