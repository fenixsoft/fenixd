# ADR-159：持久化冻结集契约演进走条目级版本戳+登记式迁移链，未登记段 fail-closed

date: 2026-09-24
status: accepted

## Context

冻结场景集被多轮验证复用，验收契约规则会演进（如 web 场景新增 navigate 硬要求）；改根节点形态会撞坏全部读写端，直接拒绝旧集会把可用场景整批判 corrupt 走人工。

## Decision

- 契约版本落条目级字段（与既有 schema_version 同层），根节点形态不变；缺失或非整型视为 1（存量兼容）。
- 全部写盘路径共用写端恒盖当前版本戳：新产出的冻结集天然达标，下轮加载零迁移，不产生「新产物被判旧契约」窗口。
- 迁移按版本登记表组织、循环推进、支持跳版本（前段产物直接喂后段）；未登记版本段 fail-closed 回既有人工通道，禁猜禁跳过；迁移为纯函数不落盘，外部输入（如被测基址）由调用方注入，禁反向依赖上层。
- 全量过时（迁移结果为空）→ 删除冻结文件并本轮回落到生成通道，不置 blocked、不在加载点内递归调用生成流程；部分过时 → WARNING 列出 id、剔除后续行。
- 迁移前备份原文件（同目录、下轮加载忽略该名）；写回失败 ERROR 留痕并照常以内存结果继续（下轮再迁即幂等）；迁移后二次验收失败走既有人工通道，处置文本给出备份恢复指引，禁静默吞掉、禁再自动重出。

## Consequences

冻结集契约演进零停摆、零手工迁移；新增版本=追加一个迁移函数加一个登记项；坏迁移有备份回退路径且不掩盖真实场景缺陷。
