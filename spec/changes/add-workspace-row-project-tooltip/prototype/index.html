胶囊风格（二选一，作用于上方全部卡片）

方案A 直接沿用台账 OV_TONE 软底浅胶囊（与详情概览表格 1:1 同源）；方案B 按深色卡面做同相透明底派生（文字亮化）。默认 A。

设计说明（色值与规则出处）

  • 深卡规格：逐值取自 dsh web 原生 tooltip 实测 — 底 #2C2C2E、圆角 16px、内距 12/16、阴影三层（1px/4px/12px 32px）、标题 #fff 14/20、次文本 #cfd3d6 12/16；无箭头，出现于行右侧（side=right），原生 500ms 延迟保留。
  • 胶囊规格：999 胶囊 · 12px · padding-inline 9 · weight 500，tone 色对逐值取自概览台账单源 OV_TONE；状态→tone 映射逐值取自 STATUS_META（阻塞/有Bug=critical、已推送/完成/已验证=good、实现中=warning、评审中/已实现=aqua、验证中/就绪=info、草稿=muted）。
  • 内容行序：名称+运行态 / 路径 / 简介一行 / 状态胶囊 / 任务与活跃 Agent — 与概览台账 ProjectCell 行序一致；路径行沿用原生 tooltip 既有内容，Created 时间行不再保留（概览台账无此列，可批注恢复）。
  • 运行态胶囊：运行中=good / 未运行=warning / 运行中·未托管=warning，与台账名称行同口径。
  • 溢出规则：胶囊超过 4 个折叠「+N」muted 胶囊（tooltip 窄面特有；台账不折叠）。
  • null 口径：任务/Agent 无数据显示「—」不显 0（0 是真实数值时照常显示，如变体⑤ Agent 0）；简介空显「暂无简介」（与台账同文案）。
  • 数值排版：任务 x/y、Agent 数一律 tabular-nums。
  • 红线遵守：本页零 animation/transition（悬停即时显隐）；字号只用 12/14/16 阶内值；卡片宽 300px（原生内容自宽 244px，富内容放宽并保持同内距）。
  • 未纳入：问题数（problems）与 SPEC 总数列未放（用户未点名、避免拥挤），需要可批注追加。
  • 实现要点（SPEC 细化，非本页职责）：fenix 行悬停项目名时抑制 dsh 原生 Tooltip 并挂自绘同规格卡，数据取 /api/projects 的 ProjectSummary（60s 随 projectSync 刷新）；非 fenix 行零侵入。
