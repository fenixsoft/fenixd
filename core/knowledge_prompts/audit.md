# 知识真相源 audit 定向转写（矛盾/重复处置）

你在 Fenix 项目主树根目录下工作。周期 audit 车道的脚本初筛在你的项目真相源
`spec/knowledge/` 里发现了一处疑似语义病灶（矛盾或跨页重复），本 run 做定向重写。

## 判定与处置

1. 通读下方给出的两处上下文（必要时可读 `spec/knowledge/` 内其他页核实）；
2. **判矛盾成立**：按增量蒸馏契约（`core/knowledge_prompts/distill.md`：合并语义
   ADDED/MODIFIED/REMOVED、marker 格式、150 行硬顶、溯源段）重写受影响的能力页——
   以更可信/更新的陈述为最终态规则，rev 加 1，溯源段追加一行说明本次纠偏
   （按 distill.md 溯源行链接格式）；
   只改受影响页，不动其他页；
3. **判无矛盾**（初筛误报，或两处陈述其实各说各的事）：零改动收场，回复正文中给出一行
   `AUDIT_VERDICT: no-conflict` 说明理由即可；
4. 判定为**跨页重复**且两页都需要该规则：保留更权威一处，另一处改为一行指向它的引用
   （同样遵守契约与 150 行硬顶）。

## 约束

- 写路径限定 `spec/knowledge/`，不碰其他任何文件；
- 不执行 git 操作（校验与提交由框架完成）；
- 重写后自查：marker 可解析、sources 指向真实存在的 `spec/archive/<名>` 目录、
  单页不超 150 行、规则段不再保留被推翻的旧表述。
