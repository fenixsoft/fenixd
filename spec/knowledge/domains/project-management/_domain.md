# 项目接入与生命周期

项目接入与生命周期。本域能力条目清单如下（能力页由存量回填批次逐步产出，落盘后此处升级为链接）。

## 能力页

- `project-discovery` — 项目发现、注册与监控接入
- `project-description` — 项目描述信息维护
- `project-lifecycle-control` — 项目启用/停用等生命周期控制
- `freeze-stop-inflight-agents` — 项目冻结时停止在飞 agent
- `delete-stop-inflight-agents` — 项目删除时停止在飞 agent
- [project-init-seeding](project-init-seeding.md) — 项目初始化骨架播种（fenix-init）
- [fenix-setup-skill](fenix-setup-skill.md) — 框架初始化与启动入口（/fenix-setup）
- [project-log](project-log.md) — 项目追加式运维日志（PROJECT_LOG.md）
